1. Informed Search

Informed search is a search technique that uses additional knowledge about the problem to guide the search toward the goal.

This additional information is usually represented by a heuristic function.

Uninformed Search: Searches without knowing which direction is better.

Informed Search: Uses a heuristic to estimate which direction is better.

Main Informed Search Techniques

  • Greedy Best-First Search
  • A* Search

2. Heuristic Function

A heuristic function estimates the cost of reaching the goal from a particular node.

h(n) = estimated cost from node n to the goal

Here:

  • h(n) = heuristic value
  • n = current node

Example

Suppose we want to travel from City A to City D. If our estimate of the remaining distance from B to D is 10 km:

h(B) = 10

The heuristic does not necessarily give the exact cost. It gives an estimate.

3. Good Heuristic

A useful heuristic should provide a reasonable estimate without overestimating the actual remaining cost when optimal A* search is required.

Admissible Heuristic

A heuristic is admissible if it never overestimates the true cost to reach the goal.

h(n) ≤ h*(n)

Where h*(n) is the actual minimum cost from n to the goal.

Example

If the actual remaining cost is 10:

h(n) = 7 → admissible h(n) = 10 → admissible h(n) = 12 → not admissible

4. Consistent Heuristic

A heuristic is consistent if, for every node n and successor n':

h(n) ≤ c(n,n') + h(n')

This is also called the triangle inequality condition.

Every consistent heuristic is admissible under the usual non-negative path-cost assumptions.

5. Greedy Best-First Search

Greedy Best-First Search selects the node that appears closest to the goal according to the heuristic.

f(n) = h(n)
Memory Trick:

Greedy → Look only at h(n).

Algorithm

Put the initial node in the priority queue.
Select the node having the smallest h(n).
Expand that node.
Add its successors.
Continue until the goal is reached.

6. Greedy Best-First Search — Solved Problem

Consider the following graph.

S / \ A B / \ \ C D E \ / F-----G | H

Suppose the heuristic values are:

Node h(n)
S 8
A 6
B 3
C 5
D 4
E 2
H 0

Step 1

Start = S Open: S(8)

Step 2

Expand S.

A(6), B(3) Choose B because: 3 < 6

Step 3

Expand B.

E(2) Open: E(2), A(6) Choose E.

Step 4

Continue toward the smallest heuristic.

The search always chooses the node with the smallest h(n).
Greedy search can reach a goal quickly, but it does not guarantee the lowest-cost solution.

7. A* Search

A* combines the actual cost already travelled with an estimate of the remaining cost.

f(n) = g(n) + h(n)

Where:

  • g(n) = actual cost from start to n
  • h(n) = estimated cost from n to goal
  • f(n) = estimated total solution cost
Memory Trick:

A* = Already travelled + Ahead estimate

f(n) = g(n) + h(n)

8. A* — Step-by-Step Solved Problem

Consider the following weighted graph.

S / \ 2/ \4 A B 3/ \2 \3 C D E \ \ / 4\ 5\ /2 G

Goal = G

Assume the heuristic values are:

Node h(n)
S 7
A 6
B 5
C 4
D 4
E 2
G 0

Step 1 — Start

S g(S) = 0 h(S) = 7 f(S) = g(S) + h(S) = 0 + 7 = 7

Step 2 — Expand S

From S:

A: g(A) = 2 h(A) = 6 f(A) = 2 + 6 = 8 B: g(B) = 4 h(B) = 5 f(B) = 4 + 5 = 9

Select A because:

f(A) = 8 < f(B) = 9

Step 3 — Expand A

A produces C and D.

C: g(C) = 2 + 3 = 5 h(C) = 4 f(C) = 5 + 4 = 9 D: g(D) = 2 + 2 = 4 h(D) = 4 f(D) = 4 + 4 = 8

Lowest f-value is D = 8.

Step 4 — Expand D

D → G g(G) = 4 + 5 = 9 h(G) = 0 f(G) = 9 + 0 = 9

Step 5 — Compare Remaining Nodes

B = 9 C = 9 G = 9

A* selects a node with the lowest f-value. With equal values, the exact tie-breaking rule can affect the order of expansion.

Important A* Calculation:

Always calculate:

f(n) = g(n) + h(n)
In an exam, show every g(n), h(n) and f(n) calculation. This makes the A* solution easy to follow and earns method marks.

9. A* — Another Easy Numerical

Suppose three nodes are available:

Node g(n) h(n) f(n)
A 4 7 11
B 5 3 8
C 2 8 10
A* selects:

B

because:
f(B) = 8

is the smallest f-value.

10. Greedy vs A*

Greedy Best-First A*
f(n) = h(n) f(n) = g(n) + h(n)
Uses estimated remaining cost Uses actual + estimated cost
Not generally optimal Optimal under standard conditions
Can be faster in some cases Usually considers more cost information

11. Knowledge-Based Agents

A knowledge-based agent uses stored knowledge and reasoning to decide what action should be performed.

Main Components

  • Knowledge Base
  • Inference mechanism
  • Percepts
  • Actions
Environment ↓ Percept ↓ Knowledge Base ↓ Inference ↓ Action ↓ Environment

12. Knowledge Base

A knowledge base contains facts and rules about the world.

Example

Fact: It is raining. Rule: If it is raining, then the road may be wet. Inference: The road may be wet.

The agent uses the facts and rules to derive new information.

13. Wumpus World

Wumpus World is a classic AI environment used to explain knowledge-based reasoning.

Main Elements

  • Wumpus: Dangerous creature.
  • Pits: Dangerous locations.
  • Gold: Desired object.
  • Agent: Explores the environment.
+-----+-----+-----+-----+ | | | | | | | | W | | +-----+-----+-----+-----+ | | P | | | | | | | | +-----+-----+-----+-----+ | | | G | | | A | | | | +-----+-----+-----+-----+ A = Agent P = Pit W = Wumpus G = Gold

14. Wumpus World Percepts

Percept Meaning
Stench Wumpus is in an adjacent square.
Breeze A pit is in an adjacent square.
Glitter Gold is in the current square.
Bump Agent hit a wall.
Scream Wumpus has been killed.

15. Wumpus World — Simple Reasoning

Suppose the agent is at square (1,1).

The agent detects a Breeze.

A breeze means that a pit is present in one of the neighboring squares.

Breeze(1,1) Therefore: Pit(1,2) OR Pit(2,1)

The agent cannot immediately conclude which square contains the pit.

This is an example of reasoning using knowledge and available percepts.

16. Propositional Logic

Propositional logic represents knowledge using propositions that are either true or false.

Proposition

A proposition is a declarative statement that has a truth value.

P = It is raining. Q = The road is wet.

Each proposition can be:

  • True
  • False
A proposition cannot be both true and false at the same time under classical two-valued propositional logic.

24. Solved Propositional Logic Problem

Given:

P = It is raining. Q = The road is wet. Knowledge: P → Q P

Prove Q.

Step 1

We know:

P → Q

Step 2

We also know:

P

Step 3

If P is true and P implies Q, then Q must be true.

Therefore:

Q is true.

The road is wet.

25. Inference

Inference is the process of deriving new knowledge from existing facts and rules.

Facts + Rules ↓ Inference ↓ New Knowledge

26. Modus Ponens

Modus Ponens is a basic inference rule.

P → Q

P
─────────
∴ Q

Example

If a student studies, then the student passes. Student studies. Therefore, the student passes.
Conclusion: The student passes.

27. Modus Tollens

Modus Tollens is another important inference pattern.

P → Q

¬Q
─────────
∴ ¬P

Example

If the system is connected, then the status is online. The status is not online. Therefore, the system is not connected.

28. Model Checking

Model checking can be used to determine whether a knowledge base entails a query by considering possible models.

KB ⊨ α

This means:

Every model in which KB is true also makes α true.

29. Solved Logic Problem — Truth Table

Determine whether:

(P ∧ Q) → P

is always true.

Step 1 — Construct P ∧ Q

P Q P ∧ Q (P ∧ Q) → P
T T T T
T F F T
F T F T
F F F T
Since the final column is true for every possible combination:

(P ∧ Q) → P is a tautology.

30. Solved Logic Problem — Deriving a Conclusion

Given:

P → Q Q → R P

Prove R.

Step 1

From:

P → Q and P

By Modus Ponens:

Q

Step 2

We have:

Q → R and Q

By Modus Ponens:

R
Therefore, R is proved.
