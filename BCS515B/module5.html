1. Inference in Artificial Intelligence

Inference is the process of deriving new information from known facts and rules.

Known Facts + Rules → New Knowledge

Example

Student(Maha)
Student(x) → Learner(x)

From these two statements we can infer:

Learner(Maha)

Types of Inference

  • Forward Chaining
  • Backward Chaining
  • Resolution
Remember:

Forward Chaining → Facts to Goal
Backward Chaining → Goal to Facts
Resolution → Prove a statement by contradiction

2. Backward Chaining

Backward chaining is a goal-driven inference method.

Instead of starting with known facts, it starts with the desired goal and works backward to find facts that support the goal.

Goal ↓ Find Rule ↓ Find Required Conditions ↓ Check Facts

Steps

  1. Start with the query or goal.
  2. Find a rule that can produce the goal.
  3. Replace the goal with the rule's conditions.
  4. Check whether those conditions are known.
  5. Continue recursively.
  6. If all conditions are satisfied, the goal is proved.

🔥 Solved Problem 1 — Simple Backward Chaining

Facts:

Student(Maha)

Rules:

Student(x) → Learner(x)
Learner(x) → Intelligent(x)

Goal: Intelligent(Maha)

Step 1: Start with the goal
Intelligent(Maha)
Step 2: Find a rule that concludes the goal
Rule:
Learner(x) → Intelligent(x)

Therefore we need:
Learner(Maha)
Step 3: Find a rule for Learner(Maha)
Rule:
Student(x) → Learner(x)

Therefore we need:
Student(Maha)
Step 4: Check the fact
Given:
Student(Maha)

The fact is TRUE.
Therefore:

Student(Maha) ↓ Learner(Maha) ↓ Intelligent(Maha)

Goal proved.

Smart(Maha)

LearnsAI(x) ∧ Smart(x) → GoodStudent(x)

Goal:
GoodStudent(Maha)

Find rule:
LearnsAI(x) ∧ Smart(x) → GoodStudent(x)
Therefore we need:

Smart(Maha)

Smart(Maha) is already a fact.

Now prove LearnsAI(Maha).

We have:

Therefore:
LearnsAI(Maha) ✔

GoodStudent(Maha) is TRUE.

3. Resolution

Resolution is an inference rule used in automated reasoning and theorem proving.

It is commonly used by converting logical statements into Conjunctive Normal Form (CNF).

Basic Resolution Rule

P ∨ Q
¬Q ∨ R
─────────
P ∨ R

Important Idea

Resolution eliminates complementary literals.

Q and ¬Q

are complementary literals.

Resolution by Refutation

To prove a statement, assume its negation and try to derive a contradiction.

Knowledge Base + ¬Goal ↓ Resolution ↓ Empty Clause ↓ Goal proved

🔥 Solved Problem — Resolution

Prove R using the following clauses:

1. P ∨ Q
2. ¬Q ∨ R
3. ¬P
Step 1: Start with Clause 1 and Clause 3
Clause 1:
P ∨ Q

Clause 3:
¬P
Step 2: Resolve P and ¬P
Remove P and ¬P.

Remaining:
Q
Step 3: Use Clause 2
Clause 2:
¬Q ∨ R
We have:
Q
and:
¬Q ∨ R
Step 4: Resolve Q and ¬Q
Remaining literal:
R
Therefore:

R is proved.

CNF Reminder

A formula is in Conjunctive Normal Form when it is an AND of OR clauses.

(P ∨ Q) ∧ (¬R ∨ S)

4. Classical Planning

Classical planning is the process of finding a sequence of actions that transforms an initial state into a desired goal state.

Initial State ↓ Action 1 ↓ Action 2 ↓ Action 3 ↓ Goal State

Components of Classical Planning

  • Initial state
  • Goal state
  • Actions
  • Preconditions
  • Effects

Action Representation

An action can be represented using:

Action
Preconditions
Effects

Example — Pick Up an Object

Action: Pickup(A)

Preconditions: OnTable(A) ∧ Clear(A)

Effects: Holding(A) ∧ ¬OnTable(A)

Types of Effects

  • Add effects: Facts that become true.
  • Delete effects: Facts that become false.

5. State-Space Search

State-space search represents planning as a search problem. Each state represents a possible situation and each action moves the system to another state.

Forward State-Space Search

Starts from the initial state and applies actions until the goal is reached.

Initial State → Successor State → Successor State → Goal

Backward State-Space Search

Starts from the goal and searches backward for actions that could produce it.

Goal → Previous State → Previous State → Initial State

🔥 Solved Planning Problem

Consider a simple robot that must move a box from one location to another.

Initial State:

At(Robot, A)
At(Box, A)

Goal:

At(Box, B)

Actions:

Move(A,B)
Preconditions: At(Robot,A)

Effect: At(Robot,B)
Push(A,B)
Preconditions: At(Robot,A) ∧ At(Box,A)

Effects: At(Robot,B) ∧ At(Box,B)
Step 1: Initial state
At(Robot,A)
At(Box,A)
Step 2: Check Push(A,B)
Preconditions:
At(Robot,A) ✔
At(Box,A) ✔

Both conditions are satisfied.
Step 3: Apply Push(A,B)
Effects:
At(Robot,B)
At(Box,B)
Goal:
At(Box,B)

Goal achieved.

6. Planning Graph

A Planning Graph is a layered graph used for planning and finding possible actions and states.

Main Layers

  • S-level: State level
  • A-level: Action level
S0 ↓ A0 ↓ S1 ↓ A1 ↓ S2

State Level

Contains propositions that may be true at that point.

Action Level

Contains actions whose preconditions can be satisfied.

Mutex Relations

Mutex means mutually exclusive. Two actions or propositions may not be simultaneously achievable.

Types of Action Mutex

  • Inconsistent effects
  • Interference
  • Competing needs

Example Planning Graph

S0:
At(Robot,A)
At(Box,A)

↓

A0:
Push(A,B)

↓

S1:
At(Robot,B)
At(Box,B)
Since At(Box,B) appears in S1, the goal can be achieved in this example.

7. Complete Classical Planning Example

Consider the following problem:

A robot is at location A and a package is at location A. The robot must deliver the package to location B.

Initial State

At(Robot,A)
At(Package,A)

Goal State

At(Package,B)

Action

Deliver(A,B)

Preconditions: At(Robot,A) ∧ At(Package,A)

Effects: At(Robot,B) ∧ At(Package,B)

Step-by-Step Solution

Step 1 — Initial state
Robot is at A.
Package is at A.
Step 2 — Check preconditions
At(Robot,A) → TRUE
At(Package,A) → TRUE
Step 3 — Apply action
Deliver(A,B)
Step 4 — Apply effects
At(Robot,B)
At(Package,B)
Final Answer:

The package reaches B.
Therefore the goal state is achieved.

11. Important VTU Exam Questions

2-Mark Questions

1. Define inference.
Inference is the process of deriving new knowledge from known facts and rules.
2. What is backward chaining?
Backward chaining is a goal-driven inference method that starts with the goal and works backward toward known facts.
3. What is resolution?
Resolution is an inference rule used for automated theorem proving by eliminating complementary literals.
4. Define classical planning.
Classical planning is the process of finding a sequence of actions that transforms an initial state into a desired goal state.
5. What is a planning graph?
A planning graph is a layered representation containing state and action levels used for solving planning problems.
6. What is mutex?
Mutex means mutually exclusive. It represents actions or propositions that cannot occur together under the given planning constraints.
