1. Introduction to Problem Solving

An intelligent agent often needs to decide what actions it should perform in order to achieve a desired goal.

Problem solving is the process of finding a sequence of actions that leads from an initial state to a goal state.

Basic idea:

Initial State → Actions → Intermediate States → Goal State

Example

Suppose a person wants to travel from City A to City D.

The cities are states and travelling between cities represents actions.

Initial State = City A
Goal State = City D
Solution = A → B → D

2. Problem-Solving Agent

A problem-solving agent is a goal-based agent that decides what actions should be taken to achieve a particular goal.

Four Main Steps

Goal Formulation
Decide what the agent wants to achieve.
Problem Formulation
Define the initial state, actions, transition model, goal test and path cost.
Search
Find a sequence of actions that reaches the goal.
Execution
Execute the selected actions.

General Flow

Goal ↓ Problem Formulation ↓ Search ↓ Solution ↓ Execution

3. Problem Formulation

A well-defined problem can be represented using five important components.

Component Meaning
Initial State The state where the problem starts.
Actions Possible actions available from a state.
Transition Model Describes the result of performing an action.
Goal Test Checks whether the current state is the goal.
Path Cost Total cost of the actions used in a solution.

Example: Route Finding

Find a route from A to D.

A ─── B ─── D │ └─── C ─── D
  • Initial state: A
  • Actions: Move to connected city
  • Transition model: Moving to another city
  • Goal: Reach D
  • Path cost: Sum of road costs

4. Example Problem — 8-Puzzle

The 8-puzzle consists of eight numbered tiles and one blank space arranged on a 3 × 3 board.

Initial State

1 2 3 4 _ 6 7 5 8

Goal State

1 2 3 4 5 6 7 8 _

The blank space can move up, down, left or right, depending on its position.

Important: The search algorithm explores different possible states until it reaches the goal state.

5. Searching for Solutions

Search is the process of systematically exploring the state space to find a path from the initial state to a goal state.

Search Tree

A / | \ B C D / \ | E F G

Here, A is the root or initial state. E, F and G are deeper states.

Important Search Terms

  • Node: Represents a state.
  • Root: Initial state.
  • Goal node: Desired state.
  • Depth: Number of edges from root.
  • Path: Sequence of nodes.
  • Branching factor: Number of successors generated by a node.

6. Uninformed Search Strategies

Uninformed search is also called blind search.

It does not use additional information about how close a state is to the goal.

Main Uninformed Search Methods

  1. Breadth-First Search (BFS)
  2. Uniform-Cost Search (UCS)
  3. Depth-First Search (DFS)
  4. Depth-Limited Search (DLS)
  5. Iterative Deepening Search (IDS)
  6. Bidirectional Search

7. Breadth-First Search (BFS)

Breadth-First Search explores nodes level by level.

BFS uses a FIFO queue.

Memory trick:
BFS → Queue → Level by Level

Algorithm

  1. Put the initial node into the queue.
  2. Remove the first node from the queue.
  3. Check whether it is the goal.
  4. If not, add its unvisited children to the queue.
  5. Repeat until the goal is found or the queue becomes empty.

8. BFS — Solved Problem

Consider the following graph.

A / | \ B C D / \ | E F G / H

Find a path from A to H using BFS.

Step 1 — Start

Queue = [A] Visited = []

Remove A.

Queue = [B, C, D] Visited = [A]

Step 2 — Expand B

Queue = [C, D, E, F] Visited = [A, B]

Step 3 — Expand C

Queue = [D, E, F] Visited = [A, B, C]

Step 4 — Expand D

Queue = [E, F, G] Visited = [A, B, C, D]

Step 5 — Expand E

Queue = [F, G] Visited = [A, B, C, D, E]

Step 6 — Expand F

Queue = [G, H] Visited = [A, B, C, D, E, F]

Step 7 — Remove H

H is the goal.

Solution Path:

A → B → F → H

9. BFS Properties

Property BFS
Data structure FIFO Queue
Complete Yes, if branching factor is finite
Optimal Yes, when all step costs are equal
Time complexity O(bd)
Space complexity O(bd)

Here:

  • b = branching factor
  • d = depth of shallowest goal

10. Uniform-Cost Search (UCS)

Uniform-Cost Search expands the node having the lowest path cost.

Memory trick:
UCS → Lowest Cost First

UCS uses a priority queue.

g(n) = Cost of path from initial state to node n

11. UCS — Step-by-Step Solved Problem

Consider this weighted graph:

A / \ 2/ \5 B C / \ \ 4/ \1 \2 D E F \ / \3 /1 G

Find the least-cost path from A to G.

Step 1

Start from A.

A = 0 Priority Queue: A(0)

Step 2

Expand A.

B = 2 C = 5 Priority Queue: B(2), C(5)

Step 3

Select B because its cost 2 is smaller than 5.

Expand B D = 2 + 4 = 6 E = 2 + 1 = 3 Priority Queue: E(3), C(5), D(6)

Step 4

Select E because it has the lowest cost.

Expand E G = 3 + 3 = 6 Priority Queue: C(5), D(6), G(6)

Step 5

Select C.

Expand C F = 5 + 2 = 7 Priority Queue: D(6), G(6), F(7)

Step 6

The next lowest-cost node is G with cost 6.

Goal reached.

Path:
A → B → E → G

Total Cost:
2 + 1 + 3 = 6
Important: UCS does NOT simply choose the nearest-looking node. It always considers the accumulated path cost.

12. UCS Properties

Property UCS
Data structure Priority Queue
Selection rule Lowest path cost
Complete Yes, under standard positive-cost assumptions
Optimal Yes, when step costs are positive
Cost function g(n)

13. Depth-First Search (DFS)

Depth-First Search explores one branch as deeply as possible before backtracking.

Memory trick:
DFS → Stack → Go Deep First

DFS can be implemented using a stack or recursion.

Basic Algorithm

  1. Start at the initial node.
  2. Visit the node.
  3. Select one unvisited child.
  4. Continue deeper.
  5. If no child is available, backtrack.
  6. Continue until the goal is found.

14. DFS — Solved Problem

Use the same graph:

A / | \ B C D / \ | E F G / H

Assume children are explored from left to right. Find the path from A to H.

Step-by-Step

Start at A A ↓ B ↓ E

E has no unvisited child, so backtrack to B.

A → B → E ↑ Backtrack

Now explore F.

A → B → F → H

H is the goal.

DFS Solution:

A → B → F → H

15. DFS Properties

Property DFS
Data structure Stack / Recursion
Complete No, in general
Optimal No, in general
Time complexity O(bm)
Space complexity O(bm)

Here m is the maximum depth of the search tree.

16. Depth-Limited Search (DLS)

Depth-Limited Search is DFS with a fixed depth limit.

DFS + Depth Limit = DLS

The search does not continue below the specified depth.

Example

Depth 0: A Depth 1: B C Depth 2: D E F G Depth 3: H

If the depth limit is 2, the search will not explore H because H is at depth 3.

17. DLS — Solved Problem

Consider:

A / \ B C / \ D E / F

Goal = F

Depth limit = 2

Depth Calculation

A = depth 0 B = depth 1 D = depth 2 F = depth 3

Since the limit is 2, F cannot be explored.

Result:

Goal F is not found because it is beyond the depth limit.

If the limit is increased to 3, F can be found.

18. Iterative Deepening Search (IDS)

Iterative Deepening Search repeatedly performs depth-limited search with increasing depth limits.

Limit 0 → Limit 1 → Limit 2 → Limit 3 → ...
Memory trick:
IDS = DLS repeated with increasing limits.

19. IDS — Step-by-Step Solved Problem

Consider:

A / \ B C / \ D E / F

Goal = F

Iteration 1 — Limit 0

A Goal F not found.

Iteration 2 — Limit 1

A ├── B └── C Goal F not found.

Iteration 3 — Limit 2

A ├── B │ ├── D │ └── E └── C Goal F not found.

Iteration 4 — Limit 3

A └── B └── D └── F Goal found.
Solution:

A → B → D → F

20. IDS Properties

Property IDS
Technique Repeated DLS
Complete Yes, under standard finite-branching assumptions
Optimal Yes, when all step costs are equal
Memory Low compared with BFS

21. Bidirectional Search

Bidirectional Search performs two simultaneous searches:

  • One search starts from the initial state.
  • Another search starts from the goal state.
  • The searches continue until they meet.
Start → → → Meeting Point ← ← ← Goal

Example

A → B → C → D → E Forward search: A → B → C Backward search: E → D → C Meeting point = C
Final Path:

A → B → C → D → E

Important Requirement

We need a way to generate predecessors from the goal or otherwise search backward effectively.

22. Comparison of Uninformed Search

Method Data Structure Complete? Optimal? Main Idea
BFS Queue Yes* Yes* Level by level
UCS Priority Queue Yes* Yes* Lowest path cost
DFS Stack No* No Go deep first
DLS Stack / Recursion Depends on limit No DFS with depth limit
IDS Repeated DLS Yes* Yes* Increase depth gradually
Bidirectional Depends on search Usually with suitable setup Depends on search Search from both ends

*The exact guarantees depend on assumptions such as finite branching, edge costs and repeated-state handling.

23. BFS vs DFS

BFS DFS
Uses Queue Uses Stack
Explores level by level Explores deeply
Requires more memory Usually requires less memory
Can find shallowest solution May find a deeper solution first
Optimal for equal step costs Not generally optimal

24. BFS vs UCS

BFS UCS
Uses depth/order Uses path cost
Queue Priority Queue
Works naturally when step costs are equal Handles different positive path costs

25. DFS vs DLS vs IDS

DFS DLS IDS
No fixed limit Fixed limit Increasing limits
Can go very deep Stops at limit Eventually reaches deeper levels
Not generally complete Depends on limit Complete under standard assumptions

26. Practice Problem — BFS

Consider:

S / | \ A B C / \ | D E F / G

Find the path from S to G using BFS.

Queue Trace

Start: [S] Expand S: [A, B, C] Expand A: [B, C, D, E] Expand B: [C, D, E] Expand C: [D, E, F] Expand D: [E, F] Expand E: [F, G] G found.
Answer:

S → A → E → G

27. Practice Problem — DFS

Using the same graph, assume left-to-right traversal.

S ↓ A ↓ D Backtrack S ↓ A ↓ E ↓ G
DFS Answer:

S → A → E → G

28. Practice Problem — UCS

Consider the weighted graph:

A --2-- B --5-- D \ | 6 1 \ | C--2--D

Find the lowest-cost path from A to D.

Calculate Possible Paths

A → B → D Cost = 2 + 5 = 7
A → B → C → D Cost = 2 + 1 + 2 = 5
Lowest-cost path:

A → B → C → D

Total cost = 5
