1. What is Artificial Intelligence?

Artificial Intelligence (AI) is a branch of computer science concerned with building systems that can perceive their environment, reason about information, learn from experience and take actions to achieve goals.

In simple words, AI tries to make machines behave intelligently.

⭐ Simple Definition

AI is the science and engineering of making intelligent machines and intelligent computer programs.

Human Intelligence vs Artificial Intelligence

Human Intelligence Artificial Intelligence
Natural ability of humans Intelligence implemented in machines
Learns from life experience Can learn from data and experience
Uses biological brain Uses computer hardware and software
Can use common sense naturally Requires algorithms and knowledge

Examples of AI

  • Voice assistants
  • Recommendation systems
  • Self-driving vehicles
  • Face recognition
  • Medical diagnosis systems
  • Fraud detection
  • Chatbots
  • Game-playing systems
  • Robotics

AI has developed using ideas from several fields. These fields provide theories, methods and techniques that help us build intelligent systems.

3. The State of the Art

The state of the art refers to the current level of development and capability of AI techniques and applications.

Important AI Application Areas

  • Natural Language Processing: Understanding and generating human language.
  • Computer Vision: Understanding images and videos.
  • Robotics: Building systems that sense and act in the physical world.

Example

Example: Self-Driving Car

A self-driving car is an intelligent agent.

  • Cameras and sensors perceive roads, vehicles and pedestrians.
  • The AI system processes the information.
  • It decides whether to accelerate, brake or turn.
  • Actuators control the steering, brakes and accelerator.

5. Agent Function

The agent function describes how an agent maps a sequence of percepts to an action.

f : P* → A

Where:

  • P* = possible sequences of percepts
  • A = set of possible actions
Example

If a vacuum-cleaner agent senses that the current location is dirty, its agent function may select the action Suck.

6. Agent Program

An agent program is the implementation of the agent function running on a physical system.

The agent function is an abstract mathematical description, whereas the agent program is the actual computer program that implements the behaviour.

Remember

Agent Function: What the agent should do.

Agent Program: The actual implementation that makes it happen.

7. Concept of Rationality

A rational agent chooses an action expected to maximize its performance measure, based on the available percept sequence and knowledge.

Rationality depends on four factors

  1. Performance measure
  2. Percept sequence
  3. Agent's prior knowledge
  4. Actions available to the agent

Example: Vacuum Cleaner

Suppose a vacuum cleaner receives a percept that the current square is dirty.

A rational action would normally be to clean the square, because this improves the performance measure.

Rational Action = Action that maximizes expected performance

⚠️ Important

Rational does not mean that the agent always makes the perfect decision.

It means the agent chooses the best action it can based on the information available to it.

11. Nature of the Environment

The nature of an environment affects how an intelligent agent should make decisions.

AI environments can be classified using several important properties.

1. Fully Observable vs Partially Observable

Fully Observable Partially Observable
Agent can access the complete relevant state of the environment. Agent cannot access the complete state of the environment.
Example: Chess Example: Driving in traffic

2. Single Agent vs Multiagent

Single Agent Multiagent
Only one agent is involved in the environment. Multiple agents interact with each other.
Example: Crossword puzzle Example: Chess

3. Deterministic vs Stochastic

Deterministic Stochastic
The next state is determined completely by the current state and action. Outcomes involve uncertainty.
Example: 8-puzzle Example: Driving

4. Episodic vs Sequential

Episodic Sequential
Each decision is independent of previous decisions. Current decisions can affect future decisions.
Example: Image classification Example: Chess

5. Static vs Dynamic

Static Dynamic
Environment does not change while the agent is deciding. Environment may change while the agent is deciding.
Example: Crossword Example: Autonomous driving

6. Discrete vs Continuous

Discrete Continuous
Finite or countable states, actions or time steps. States, actions or time can vary continuously.
Example: Chess Example: Robot movement

7. Known vs Unknown

Known Unknown
Agent knows the rules or consequences of actions. Agent must learn or discover aspects of the environment.

14. Types of Intelligent Agents

The standard agent models discussed in introductory AI include the following:

1. Simple Reflex Agent

A simple reflex agent selects actions based only on the current percept.

Current Percept → Condition → Action

Example: If the vacuum cleaner detects dirt, it performs the Suck action.

2. Model-Based Reflex Agent

A model-based reflex agent maintains an internal state that represents aspects of the world that cannot be directly observed.

3. Goal-Based Agent

A goal-based agent selects actions by considering future states and whether they help achieve a goal.

Current State + Goal → Action

4. Utility-Based Agent

A utility-based agent evaluates possible outcomes using a utility measure and chooses an action that provides a desirable expected result.

5. Learning Agent

A learning agent improves its performance through experience.

Chooses actions

Learning Element

15. Solved Problem — Vacuum Cleaner Agent

Question

Explain how a vacuum cleaner can work as an intelligent agent.

Step 1 — Sensors

The agent detects the current location and whether the location contains dirt.

Step 2 — Percept

Example percept:

[Location = A, Status = Dirty]

Step 3 — Decision

Since the location is dirty, the agent selects the Suck action.

Step 4 — Action

The actuator operates the vacuum cleaner.

Step 5 — New Percept

The agent observes the updated condition and decides what to do next.

Result

The vacuum cleaner demonstrates the basic perception → decision → action cycle of an intelligent agent.

Agent Function vs Agent Program

Agent Function Agent Program

Sensor vs Actuator

Sensor Actuator

Camera, microphone, GPS. Motor, brake, speaker, steering.

20. VTU 10-Mark Answer Writing Format

For a 10-mark question, don't write only definitions. Use a structured answer.

  1. Start with the definition.
  2. Explain the concept.
  3. Draw a neat diagram if applicable.
  4. Explain each component.
  5. Give a suitable example.
  6. Add a table for comparisons where useful.
  7. End with a short conclusion.
