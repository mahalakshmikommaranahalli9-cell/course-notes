JavaScript Calculator

🎯 Aim

To develop a simple calculator using JavaScript.

📖 Explanation

JavaScript is used to add logic and interactivity to web pages. In this program JavaScript performs basic arithmetic operations.

🛠 Use of Program

  • Perform arithmetic calculations.
  • Practice JavaScript functions.
  • Understand DOM interaction.
  • Handle user input.

💻 Complete Program

<script>

function calculate(operator){

    let a = Number(
        document.getElementById("num1").value
    );

    let b = Number(
        document.getElementById("num2").value
    );

    let result;

    if(operator === "+"){
        result = a + b;
    }
    else if(operator === "-"){
        result = a - b;
    }
    else if(operator === "*"){
        result = a * b;
    }
    else if(operator === "/"){

        if(b === 0){
            result = "Cannot divide by zero";
        }
        else{
            result = a / b;
        }

    }

    document.getElementById("result").innerHTML =
        "Result: " + result;
}

</script>

🖥 Expected Output

The calculator accepts two numbers and performs addition, subtraction, multiplication or division.
