Class Time Table

🎯 Aim

To create a class timetable using HTML table elements.

📖 Explanation

HTML tables are created using the table, row and data elements. The table can also use colspan and rowspan to combine cells.

🛠 Use of Program

  • Display tabular information.
  • Create class timetables.
  • Practice table rows and columns.
  • Understand colspan and rowspan.

💻 Complete Program

<!DOCTYPE html>

<html>

<head>

<title>Class Time Table</title>

</head>

<body>

<h1>Class Time Table</h1>

<table border="1">

<caption>5th Semester CSE - Sample Timetable</caption>

<tr>
    <th>Day</th>
    <th>9:00 - 10:00</th>
    <th>10:00 - 11:00</th>
    <th>11:00 - 12:00</th>
    <th>12:00 - 1:00</th>
</tr>

<tr>
    <th>Monday</th>
    <td>BCS501</td>
    <td>BCS502</td>
    <td>BCS503</td>
    <td rowspan="2">Lunch</td>
</tr>

<tr>
    <th>Tuesday</th>
    <td>BCS515B</td>
    <td>BCS501</td>
    <td>BCS502</td>
</tr>

<tr>
    <th>Wednesday</th>
    <td colspan="2">BCSL504 Lab</td>
    <td>BCS503</td>
    <td>BCS515B</td>
</tr>

</table>

</body>

</html>

Note: This is a sample timetable for demonstrating HTML table concepts. Replace the periods with your actual class schedule if required.

🖥 Expected Output

A timetable is displayed in rows and columns with merged cells.
