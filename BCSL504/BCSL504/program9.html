BCSL504 • PROGRAM 9

jQuery Operations

🎯 Aim

To perform DOM manipulation and animation using jQuery.

📖 Explanation

jQuery is a JavaScript library that simplifies DOM manipulation, event handling and animation.

🛠 Use of Program

  • Modify webpage content.
  • Change CSS dynamically.
  • Perform animations.
  • Handle user events.

💻 Complete Program

Hello jQuery! 
$(document).ready(function(){

    $("#hide").click(function(){
        $("#demo").hide();
    });

    $("#show").click(function(){
        $("#demo").show();
    });

    $("#animate").click(function(){
        $("#demo").animate({
            width: "300px",
            height: "200px"
        });
    });

    $("#change").click(function(){
        $("#demo").text("jQuery is Easy!");
    });

});

🖥 Expected Output

The buttons hide, show, animate and change the content of the selected element.
