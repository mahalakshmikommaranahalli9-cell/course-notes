Student Registration Form

🎯 Aim

To create a student registration form using HTML form controls.

📖 Explanation

HTML forms are used to collect information from users. Forms can contain text fields, email fields, passwords, radio buttons, checkboxes, dropdown lists and text areas.

🛠 Use of Program

  • Collect student information.
  • Create registration pages.
  • Practice HTML form elements.
  • Understand different input types.
