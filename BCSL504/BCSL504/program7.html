JSON, CSV and Hash

🎯 Aim

To understand JSON and CSV data formats and generate a hash value using JavaScript/Node.js.

📖 Explanation

JSON represents structured data using key-value pairs. CSV represents tabular data using comma-separated values. Hashing converts input data into a fixed-length value.

🛠 Use of Program

  • Store structured information.
  • Exchange data between applications.
  • Represent tabular information.
  • Understand data integrity concepts.

💻 JSON Example

{
    "name": "Mahalakshmi",
    "course": "CSE",
    "semester": 5
}

💻 CSV Example

Name,Course,Semester
Mahalakshmi,CSE,5
Student2,CSE,5
Student3,CSE,5

💻 Hash Program

const crypto = require("crypto");

const data = "Mahalakshmi";

const hash = crypto
    .createHash("sha256")
    .update(data)
    .digest("hex");

console.log("Original Data:", data);
console.log("SHA-256 Hash:", hash);

Save the code as hash.js.

Run it using: 

node hash.js

🖥 Expected Output

The JSON and CSV data can be represented as structured text files, while the Node.js program prints the SHA-256 hash of the input data.
