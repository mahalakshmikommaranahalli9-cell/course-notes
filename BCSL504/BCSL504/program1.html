HTML Basic Tags

🎯 Aim

To create a basic HTML webpage using different HTML tags for headings, paragraphs, formatting and text presentation.

📖 Explanation

HTML stands for HyperText Markup Language. It is used to create the structure of web pages. HTML provides tags for headings, paragraphs, line breaks, horizontal lines and text formatting.

🛠 Use of Program

  • Create the basic structure of a webpage.
  • Display headings and paragraphs.
  • Format important text.
  • Display mathematical expressions.
  • Understand commonly used HTML tags.

💻 Complete Program

<!DOCTYPE html>

<html>

<head>
    <title>HTML Basic Tags</title>
</head>

<body>

    <h1>Heading 1</h1>
    <h2>Heading 2</h2>
    <h3>Heading 3</h3>
    <h4>Heading 4</h4>
    <h5>Heading 5</h5>
    <h6>Heading 6</h6>

    <p>
        This is a paragraph created using HTML.
    </p>

    <br>

    <hr>

    <blockquote>
        HTML is the standard markup language
        for creating web pages.
    </blockquote>

    <pre>
This text preserves spaces
and line breaks.
    </pre>

    <b>Bold Text</b>
    <br>

    <strong>Strong Text</strong>
    <br>

    <i>Italic Text</i>
    <br>

    <em>Emphasized Text</em>
    <br>

    <u>Underlined Text</u>
    <br>

    <mark>Highlighted Text</mark>
    <br>

    <small>Small Text</small>
    <br>

    H<sub>2</sub>O
    <br>

    X<sup>2</sup>

</body>

</html>

🖥 Expected Output

The webpage displays different heading levels, paragraphs, horizontal line, quotation, formatted text, subscript and superscript.
