👋 Welcome

A practical learning space for BCSL504

Welcome to the BCSL504 Web Technology Laboratory section of Mahalakshmi's Course Notes.

This section is designed to help you understand the practical concepts of web technology through simple explanations and working programs.

Each laboratory program contains an Aim, Explanation, Use of the Program, Complete Code, Expected Output and Viva Questions.

Start with the fundamentals and gradually move towards dynamic web technologies such as JavaScript, PHP, jQuery and AJAX.

🌐 What You Will Learn

Core technologies covered in the laboratory

🧱

HTML

Learn how to structure web pages using headings, paragraphs, tables, forms and semantic elements.

🎨

CSS

⚡

JavaScript

Add calculations, interaction and dynamic behaviour to web pages.

📦

JSON

Understand structured data and conversion between JSON and JavaScript objects.

🐘

PHP

Learn server-side programming through visitor counters and sorting operations.

✨

jQuery

Perform DOM operations, append content and create animations easily.

🔄

AJAX

Load data from files and communicate with web resources without reloading the page.

📊

CSV

Understand conversion between structured JSON data and CSV format.

💡 Lab Preparation

Simple steps to prepare before your practical exam

  • Understand the aim of every program.
  • Know what each major HTML, CSS or JavaScript element does.
  • Practice typing the important portions of the programs without copying.
  • Understand the expected output before running the program.
  • Practice running HTML programs in a browser.
  • Use XAMPP or another PHP environment for PHP programs.
  • Be prepared to explain the logic during the viva.
