Semantic HTML

🎯 Aim

To create a webpage using semantic HTML elements.

📖 Explanation

Semantic HTML elements clearly describe their meaning and purpose. Examples include header, nav, main, section, article, aside and footer.

🛠 Use of Program

  • Create meaningful webpage structure.
  • Improve readability.
  • Help search engines understand content.
  • Improve accessibility.

💻 Complete Program

<header>
    <h1>My Website</h1>
</header>

<nav>
    <a href="#">Home</a>
    <a href="#">About</a>
    <a href="#">Contact</a>
</nav>

<main>

    <section>

        <h2>Web Technology</h2>

        <article>
            <h3>HTML</h3>
            <p>
                HTML creates the structure of webpages.
            </p>
        </article>

    </section>

    <aside>
        Additional Information
    </aside>

</main>

<footer>
    Copyright 2026
</footer>

🖥 Expected Output

Website Header

Navigation Menu

Main Section

Article Content
Sidebar Information
Footer
