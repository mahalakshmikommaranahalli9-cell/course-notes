AJAX and jQuery

🎯 Aim

To demonstrate AJAX operations using JavaScript and jQuery without reloading the complete webpage.

📖 Explanation

AJAX stands for Asynchronous JavaScript and XML. It allows a webpage to communicate with a server and receive data without refreshing the entire page.

🛠 Use of Program

  • Load data asynchronously.
  • Communicate with server resources.
  • Read JSON data.
  • Update webpage content dynamically.

💻 Complete Program

Output will appear here. 
function plainAjax(){

    let xhr = new XMLHttpRequest();

    xhr.open("GET", "data.txt", true);

    xhr.onload = function(){

        if(xhr.status === 200){

            document.getElementById("output")
            .innerHTML = xhr.responseText;

        }

    };

    xhr.send();
}


function jqueryAjax(){

    $.ajax({
        url: "data.txt",
        success: function(data){

            $("#output").html(data);

        }
    });

}


function getJson(){

    $.getJSON("data.json", function(data){

        $("#output").html(
            "Name: " + data.name +
            "<br>" +
            "Course: " + data.course +
            "<br>" +
            "Semester: " + data.semester
        );

    });

}


function parseJson(){

    let text = '{"name":"Mahalakshmi","course":"CSE"}';

    let data = JSON.parse(text);

    $("#output").html(
        "Name: " + data.name +
        "<br>" +
        "Course: " + data.course
    );

}

🖥 Expected Output

The requested data is loaded into the webpage without refreshing the complete page.

⚠️ How to Run

Because AJAX requests local files, run this program through a local server such as VS Code Live Server or XAMPP.

Do not simply double-click the HTML file and open it using file://.
