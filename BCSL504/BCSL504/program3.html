External CSS

🎯 Aim

To design an HTML webpage using an external CSS stylesheet.

📖 Explanation

External CSS stores styling rules in a separate CSS file. The HTML page connects to the stylesheet using the <link> element.

🛠 Use of Program

  • Separate content from presentation.
  • Reuse styles across pages.
  • Maintain consistent webpage design.
  • Make websites easier to maintain.

💻 Complete Program

<!DOCTYPE html>

<html>

<head>

<title>External CSS</title>

<link rel="stylesheet" href="program3-style.css">

</head>

<body>

<h1>Web Technology</h1>

<p>
This webpage is styled using an external CSS file.
</p>

<div class="box">
External CSS separates HTML content from styling.
</div>

</body>

</html>

CSS File: program3-style.css

body {
    background-color: #f2f2f2;
    font-family: Arial;
    text-align: center;
}

h1 {
    color: darkblue;
}

p {
    font-size: 20px;
}

.box {
    background-color: white;
    padding: 20px;
    margin: 20px;
    border: 2px solid darkblue;
}

🖥 Expected Output

The HTML webpage is displayed with the styles defined in the external CSS file.
