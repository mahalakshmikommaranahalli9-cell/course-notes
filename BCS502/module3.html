1. Network Layer Introduction

The Network Layer is the third layer of the OSI reference model.

Its main responsibility is to deliver packets from the source host to the destination host across one or more interconnected networks. 


        SENDER                                      RECEIVER

     Application                                  Application
          ↓                                            ↑
     Transport                                    Transport
          ↓                                            ↑
     Network       ──── PACKETS ────►             Network
          ↓                                            ↑
     Data Link                                    Data Link
          ↓                                            ↑
      Physical                                     Physical

                  NETWORK LAYER
             Source → Router → Router → Destination

Main Functions

  • Logical addressing
  • Routing
  • Packet forwarding
  • Internetworking
  • Fragmentation and reassembly in IPv4
  • Congestion-related support
Exam Point: The Network Layer is mainly responsible for source-to-destination delivery of packets across multiple networks.

2. Network Layer Services

The Network Layer provides services to the Transport Layer and uses the services of the Data Link Layer.

Important Services

1. Logical Addressing

Each device is identified using a logical address such as an IPv4 or IPv6 address.

2. Routing

Routing determines the path that packets should follow from source to destination.

3. Forwarding

Forwarding is the process of moving a packet from an incoming interface to the appropriate outgoing interface.

4. Internetworking

The Network Layer allows different networks to communicate with each other.

5. Fragmentation

IPv4 can divide a large packet into smaller fragments when required by the network's MTU.

3. Packet Switching

In packet switching, a message is divided into smaller units called packets.

Each packet contains control information such as source, destination and other header information. 


Original Message

┌─────────────────────────────────────────────┐
│                 MESSAGE                     │
└─────────────────────────────────────────────┘

                  ↓ Divide

┌────────┐   ┌────────┐   ┌────────┐
│Packet 1│   │Packet 2│   │Packet 3│
└────────┘   └────────┘   └────────┘

                  ↓

        ┌───────────────┐
        │     Router    │
        └───────────────┘
             ↓     ↓
          Network Network
             ↓     ↓
        ┌───────────────┐
        │   Destination │
        └───────────────┘

Types of Packet Switching

  • Datagram approach
  • Virtual circuit approach

Datagram Approach

Each packet is treated independently. Packets may follow different paths.

Example: If three packets are sent from A to B, packet 1 may use one route while packet 2 and packet 3 may use another route.

Virtual Circuit Approach

A logical path is established before data transfer. Packets normally follow the same logical path.

Datagram Virtual Circuit
Connectionless Connection-oriented
Each packet is independent Packets follow a logical path
No setup phase Setup phase required

4. IPv4 Addressing

IPv4 uses a 32-bit logical address.

The address is normally represented using four decimal octets separated by dots. 


IPv4 Address = 32 bits

        8 bits       8 bits       8 bits       8 bits

       192          168            1            10
        │             │             │             │
        └─────────────┴─────────────┴─────────────┘

              192.168.1.10

IPv4 Address Format

Each octet has values from 0 to 255.

Therefore:

Example: 192.168.1.10

Network Part and Host Part

An IP address identifies both the network and the host within that network. 


        IPv4 Address

┌───────────────────┬───────────────────┐
│   Network Part    │     Host Part     │
└───────────────────┴───────────────────┘

Example:

192.168.1.10

Network              Host

Classful IPv4 Addressing

Class First Octet Default Mask Typical Use
A 1–126 255.0.0.0 Large networks
B 128–191 255.255.0.0 Medium networks
C 192–223 255.255.255.0 Small networks
D 224–239 — Multicast
E 240–255 — Experimental
Remember: A → Large networks
B → Medium networks
C → Small networks
D → Multicast

5. Subnetting

Subnetting is the process of dividing one large network into smaller logical networks called subnets. 


             Original Network

        ┌───────────────────────┐
        │       NETWORK         │
        └───────────────────────┘
                    │
          ┌─────────┼─────────┐
          ↓         ↓         ↓

      ┌──────┐  ┌──────┐  ┌──────┐
      │Subnet│  │Subnet│  │Subnet│
      │  1   │  │  2   │  │  3   │
      └──────┘  └──────┘  └──────┘

Advantages

  • Efficient use of IP addresses
  • Reduces broadcast traffic
  • Improves network management
  • Provides logical separation
  • Can improve security and organization

Basic Formula

If n bits are borrowed for subnetting:

Number of subnets = 2n

If h bits remain for hosts:

Hosts per subnet = 2h − 2

Example

Suppose a network has a /24 prefix and 2 host bits are borrowed.

Original: /24

New prefix: /26

Number of subnets: 2² = 4

Host addresses per subnet: 2⁶ − 2 = 62

An IPv4 packet is called an IPv4 datagram.

It contains a header and data.

│                                             │

Header + Data = IPv4 Datagram

Important Header Fields

Field Purpose
Version Identifies IP version
IHL Internet Header Length

Identification Identifies fragments

TTL — Time To Live: TTL prevents packets from circulating indefinitely in a network. A router normally decreases TTL before forwarding the packet.

7. IPv6 Datagram

IPv6 was designed to overcome several limitations of IPv4, especially the shortage of IPv4 addresses.

IPv6 uses a 128-bit address.

Example IPv6 address: 2001:db8:abcd:0012::1

Important IPv6 Header Fields

Field Purpose
Version IP version
Traffic Class Traffic priority / classification
Flow Label Identifies packets belonging to a flow
Payload Length Length of payload
Next Header Identifies next header or upper-layer protocol
Hop Limit Limits packet lifetime
Source Address 128-bit source address
Destination Address 128-bit destination address

IPv4 vs IPv6

IPv4 IPv6
32-bit address 128-bit address
Decimal notation Hexadecimal notation
Header checksum present No header checksum
Broadcast supported No traditional broadcast
Routers may fragment IPv4 packets Routers do not fragment IPv6 packets

8. Routing Algorithms

Routing is the process of selecting a path for packets from source to destination. 


        A
       / \
      /   \
     B-----C
      \   /
       \ /
        D

Possible paths:

A → B → D

A → C → D

A → B → C → D

Routing algorithm selects an appropriate path.

Routing Table

Routers maintain routing information to determine where packets should be forwarded.

Destination Next Hop Metric
Network A Router 1 2
Network B Router 2 3
Network C Router 3 1

Main Routing Algorithm Categories

  • Distance Vector Routing
  • Link State Routing
  • Path Vector Routing

9. Distance Vector Routing

Distance Vector Routing is a routing method in which each router maintains information about the distance and direction to different destinations. 


        Router A
        /      \
       /        \
      B          C
       \        /
        \      /
          D

Router A maintains:

Destination     Distance     Next Hop

B                  1            B
C                  1            C
D                  2            B/C

Basic Idea

Each router shares its routing information with neighboring routers.

Routers update their routing tables when they receive better route information.

Bellman-Ford Concept

Distance Vector Routing is based on the Bellman-Ford shortest path approach.

Basic idea: New distance through neighbor = distance to neighbor + neighbor's distance to destination.

Advantages

  • Simple implementation
  • Requires less information than link-state routing
  • Suitable for smaller networks

Disadvantages

  • Slow convergence
  • Routing loops may occur
  • Count-to-infinity problem
Exam Point: Distance Vector → information exchanged with neighbors.

10. Link State Routing

In Link State Routing, each router builds a map of the network topology and calculates the shortest path. 


        A
       / \
      2   4
     /     \
    B---1---C
     \     /
      3   2
       \ /
        D

Each router knows:

• Its neighbors
• Link costs
• Network topology

Then it calculates shortest paths.

Main Steps

  1. Discover neighboring routers.
  2. Measure the cost of links.
  3. Create link-state information.
  4. Distribute link-state information.
  5. Build a topology database.
  6. Run a shortest-path algorithm.
  7. Build the routing table.

Dijkstra's Algorithm

Link State Routing commonly uses the Dijkstra shortest path algorithm.

Remember: Distance Vector → Bellman-Ford
Link State → Dijkstra

Advantages

  • Fast convergence
  • Better knowledge of network topology
  • Less chance of routing loops

Disadvantages

  • Requires more memory
  • Requires more processing
  • More complex than distance vector

11. Path Vector Routing

Path Vector Routing maintains information about the complete path to a destination rather than only the distance. 


        AS 1
          |
          |
        AS 2
          |
          |
        AS 3
          |
          |
        AS 4

Path advertised:

AS 1 → AS 2 → AS 3 → AS 4

The path itself is carried in routing information.

Features

  • Maintains path information.
  • Used mainly between autonomous systems.
  • Helps avoid routing loops.
  • Supports policy-based routing decisions.
Exam Point: Path Vector → complete path information. BGP is the major example of a path-vector routing protocol.

12. RIP — Routing Information Protocol

RIP is a distance-vector routing protocol.

Important Characteristics

  • Uses hop count as metric.
  • Maximum usable hop count is 15.
  • A metric of 16 represents unreachable.
  • Routers exchange routing information with neighbors.
  • It is designed for relatively small networks.

Router A
   |
  1 hop
   |
Router B
   |
  1 hop
   |
Router C
   |
  1 hop
   |
Router D

A → D = 3 hops
Easy Memory: RIP = Distance Vector + Hop Count

13. OSPF — Open Shortest Path First

OSPF is a link-state routing protocol used within an autonomous system.

Characteristics

  • Uses link-state information.
  • Uses shortest-path calculation.
  • Supports hierarchical routing using areas.
  • Supports authentication mechanisms.
  • Uses a cost-based metric.

                 OSPF Domain

       ┌────────────────────────┐
       │        Area 0          │

                  │

14. BGP — Border Gateway Protocol

BGP is a path-vector routing protocol used for routing between autonomous systems. 


       Autonomous System 1
              |
              |
             BGP
              |
              |
       Autonomous System 2
              |
              |
             BGP
              |
              |
       Autonomous System 3

        Inter-AS Routing

Important Features

  • Path-vector protocol
  • Used between autonomous systems
  • Supports policy-based routing
  • Uses path information
  • Designed for large-scale inter-network routing

Autonomous System

An Autonomous System (AS) is a collection of networks and routers under a common administrative control.

Easy Memory: BGP = Path Vector + Inter-AS Routing

15. Multicast and MOSPF

Multicast is a communication method in which one sender sends data to a selected group of receivers. 


                    Sender
                      │
                      │
                  ┌───┴───┐
                  │ Router│
                  └───┬───┘
              ┌───────┼───────┐
              ↓       ↓       ↓
           Receiver Receiver Receiver
              A       B       C

        One sender → Multiple selected receivers

Unicast vs Multicast vs Broadcast

Type Communication
Unicast One sender → One receiver
Multicast One sender → Selected group
Broadcast One sender → All devices in broadcast domain

MOSPF

MOSPF stands for Multicast Open Shortest Path First.

It extends OSPF concepts to support multicast routing.

Remember: OSPF → Unicast link-state routing
MOSPF → Multicast extension of OSPF

17. Important 2-Mark Questions

Q1. What is the Network Layer?

The Network Layer is the third OSI layer responsible for logical addressing, routing and delivery of packets across interconnected networks.

Q2. What is routing?

Routing is the process of selecting a path for a packet from source to destination.

Q3. What is forwarding?

Forwarding is the process of transferring a packet from an incoming interface to the appropriate outgoing interface.

Q4. What is IPv4?

IPv4 is a network-layer protocol that uses 32-bit logical addresses.

Q5. What is IPv6?

IPv6 is a network-layer protocol that uses 128-bit logical addresses.

Q6. What is subnetting?

Subnetting is the process of dividing a network into smaller logical subnetworks.

Q7. What is Distance Vector Routing?

It is a routing method where routers exchange distance and next-hop information with neighboring routers.

Q8. What is Link State Routing?

It is a routing method in which routers maintain information about network topology and calculate shortest paths.

Q9. What is RIP?

RIP is a distance-vector routing protocol that uses hop count as its metric.

Q10. What is OSPF?

OSPF is a link-state routing protocol that uses shortest-path calculation within an autonomous system.

Q11. What is BGP?

BGP is a path-vector routing protocol used mainly for routing between autonomous systems.

Q12. What is multicast?

Multicast is communication from one sender to a selected group of receivers.

22. Module 3 Summary

The Network Layer provides logical addressing, routing and packet forwarding between networks.

IPv4 uses 32-bit addresses, while IPv6 uses 128-bit addresses. Subnetting divides a network into smaller logical networks.

Routing can be studied using Distance Vector, Link State and Path Vector approaches.

RIP represents distance-vector routing, OSPF represents link-state routing, and BGP represents path-vector routing between autonomous systems.

Multicast allows delivery to a selected group of receivers, and MOSPF extends OSPF concepts for multicast routing.
