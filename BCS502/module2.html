1. Data Link Layer Introduction

Definition:

The Data Link Layer is the second layer of the OSI model. It provides reliable transfer of data frames between two directly connected nodes over a physical link.

Main Responsibilities

  • Framing
  • Physical addressing
  • Flow control
  • Error control
  • Access control

Data Link Layer Functions

1. Framing

The data received from the network layer is divided into manageable units called frames.

2. Flow Control

Flow control prevents a fast sender from overwhelming a slow receiver.

3. Error Control

It detects and sometimes corrects errors that occur during transmission.

4. Access Control

When multiple devices share the same communication medium, the data link layer determines which device can transmit.

2. Error Detection and Correction

During data transmission, bits may change because of noise, interference, attenuation or other transmission problems.

Error: A change in one or more bits of the transmitted data.

Types of Errors

Single-Bit Error

Only one bit is changed from 0 to 1 or from 1 to 0.

Example:
Sent: 1011001 Received: 1010001

Only one bit has changed.

Burst Error

Two or more bits in a data unit are affected. The corrupted bits need not be consecutive.

Sent: 1001100110 Received: 1000011110

Error Detection Techniques

  • Parity Check
  • Checksum
  • Cyclic Redundancy Check (CRC)
  • Block Coding

Error Correction

Error correction attempts to identify the error and recover the original transmitted data.

3. Block Coding

Definition:

Block coding divides a message into blocks of m bits and replaces each block with an n-bit codeword, where n is greater than m. 

       m bits
          │
          ▼
   ┌─────────────┐
   │   Encoder   │
   └─────────────┘
          │
          ▼
       n bits
      Codeword

        n > m

Redundancy

The additional bits added to the original data are called redundant bits. They help the receiver detect or correct errors.

Redundancy = n - m

Code Rate

Code Rate = m / n
Example:

If 4 data bits are converted into an 8-bit codeword:

m = 4 n = 8 Code Rate = 4 / 8 = 0.5

4. Cyclic Codes / CRC

Cyclic Redundancy Check (CRC)

CRC is an error-detection technique based on binary polynomial division. It is widely used for detecting transmission errors.

Basic CRC Process

       Dataword
          │
          ▼
    Append zeros
          │
          ▼
   Binary division
          │
          ▼
       Remainder
          │
          ▼
       Codeword

Important Terms

  • Dataword: Original data bits.
  • Divisor: Generator used for binary division.
  • Remainder: Result obtained after division.
  • Codeword: Dataword combined with the CRC remainder.

CRC Steps

  1. Let the dataword contain m bits.
  2. Let the divisor contain n bits.
  3. Append n − 1 zeros to the dataword.
  4. Perform modulo-2 binary division.
  5. The remainder is appended to the original dataword.
  6. The resulting sequence is transmitted as the codeword.
Simple Example:

Suppose:

Dataword = 1001 Divisor = 1011

The divisor has 4 bits, therefore append 3 zeros:

1001 → 1001000

Perform modulo-2 division. The resulting remainder is attached to the original dataword to form the transmitted codeword.

Modulo-2 Arithmetic

CRC uses XOR instead of ordinary subtraction.

0 XOR 0 = 0 0 XOR 1 = 1 1 XOR 0 = 1 1 XOR 1 = 0
Exam Tip:

For CRC numerical problems, remember:

Number of appended zeros = Divisor length − 1

5. Framing

Framing:

Framing is the process of dividing the stream of bits received from the network layer into manageable units called frames. 

                FRAME

┌──────────┬────────────────────┬──────────┐
│  Header  │        Data        │  Trailer │
└──────────┴────────────────────┴──────────┘

Framing Methods

  • Character-oriented framing
  • Byte stuffing
  • Bit-oriented framing
  • Bit stuffing

Byte Stuffing

In byte stuffing, special bytes are inserted into the data whenever the data contains a byte that has a special meaning.

Example:

Suppose FLAG represents the beginning or end of a frame. If FLAG appears inside the actual data, an escape byte can be inserted before it.

Original Data: A B FLAG C After Stuffing: A B ESC FLAG C

Bit Stuffing

Bit stuffing is commonly used with bit-oriented protocols. A 0 is inserted after five consecutive 1s in the data.

Original: 111111 After bit stuffing: 1111101

6. Flow Control

Definition:

Flow control controls the rate at which a sender transmits data so that a receiver can process the data properly. 

       SENDER                         RECEIVER

          │                              │
          │────── Frame 1 ──────────────►│
          │────── Frame 2 ──────────────►│
          │                              │
          │◄──────── ACK ────────────────│
          │                              │

Why Flow Control is Needed

  • Sender may be faster than receiver.
  • Receiver may have limited buffer space.
  • Prevents loss of frames due to buffer overflow.

Main Flow Control Techniques

  • Stop-and-Wait
  • Sliding Window

7. Stop-and-Wait Protocol

In Stop-and-Wait, the sender transmits one frame and waits for an acknowledgement before sending the next frame. 

 Sender                         Receiver
   │                               │
   │────── Frame 1 ───────────────►│
   │                               │
   │◄────────── ACK ───────────────│
   │                               │
   │────── Frame 2 ───────────────►│
   │                               │
   │◄────────── ACK ───────────────│
   │                               │

Advantages

  • Simple implementation.
  • Easy error handling.
  • Suitable for low-speed links.

Disadvantage

It can be inefficient when the propagation delay is large because the sender spends significant time waiting for acknowledgements.

Sliding Window allows multiple frames to be transmitted before receiving acknowledgements. 

Frame Numbers

          Window

Advantages

  • Better link utilization.
  • Higher throughput.
  • Multiple frames can be in transit.

Types

  • Go-Back-N ARQ
  • Selective Repeat ARQ

9. Error Control

Error control combines error detection, acknowledgement, retransmission and timeout mechanisms to provide reliable delivery.

Important Components

  • Error detection
  • ACK — acknowledgement
  • NAK — negative acknowledgement
  • Timeout
  • Retransmission

ARQ

ARQ stands for Automatic Repeat reQuest. It uses acknowledgements and retransmission to recover from errors.

Types of ARQ

10. HDLC

HDLC — High-Level Data Link Control

HDLC is a bit-oriented data link layer protocol used for reliable communication over point-to-point and multipoint links.

HDLC Frame Format

┌──────┬───────┬──────┬──────────┬──────┬──────┐
│ Flag │ Address│Control│ Information│ FCS │ Flag │
└──────┴───────┴──────┴──────────┴──────┴──────┘

HDLC Fields

Field Purpose
Flag Marks beginning and end of frame.
Address Identifies the secondary station.
Control Specifies the type and control information.
Information Carries user data.
FCS Frame Check Sequence used for error detection.

Types of HDLC Frames

  • I-Frame: Information frame.
  • S-Frame: Supervisory frame.
  • U-Frame: Unnumbered frame.

12. Random Access

In random access, all stations have equal opportunity to access the shared medium.

Important Random Access Protocols

  • ALOHA
  • Slotted ALOHA
  • CSMA
  • CSMA/CD
  • CSMA/CA

ALOHA

A station transmits whenever it has data. If a collision occurs, the frame is retransmitted after a random waiting period.

Slotted ALOHA

Time is divided into slots. A station can transmit only at the beginning of a time slot.

ALOHA Slotted ALOHA
Transmission can begin at any time. Transmission begins only at slot boundaries.
Higher collision possibility. Lower collision possibility.

CSMA

CSMA stands for Carrier Sense Multiple Access. A station senses the channel before transmitting.

CSMA/CD

CSMA/CD stands for Carrier Sense Multiple Access with Collision Detection. It detects collisions while transmission is taking place.

CSMA/CA

CSMA/CA stands for Carrier Sense Multiple Access with Collision Avoidance. It attempts to avoid collisions before they occur. It is associated with wireless LAN communication.

13. Controlled Access

In controlled access, stations coordinate their access to the shared medium.

Main Methods

  • Reservation
  • Polling
  • Token Passing

Polling

A central controller asks each station whether it wants to transmit.

14. Checksum

Checksum is an error-detection technique in which data is divided into fixed-size units and added using one's complement arithmetic.

Basic Steps

  1. Divide data into equal-sized words.
  2. Add all words using one's complement addition.
  3. Take the one's complement of the sum.
  4. The result is the checksum.
  5. The checksum is transmitted along with the data.
Data Words
   │
   ▼

│ Add Words   │
└──────┬──────┘

Conceptual Example:
Word 1 = 1010 Word 2 = 1100 Word 3 = 0110 ↓ One's complement addition ↓ Sum ↓ One's complement ↓ Checksum

16. Important Comparisons

Stop-and-Wait vs Sliding Window

Stop-and-Wait Sliding Window
One frame at a time. Multiple frames can be transmitted.
Simple. More complex.
Lower efficiency. Higher efficiency.
Suitable for simple links. Suitable for high-delay links.

CRC vs Checksum

CRC Checksum
Uses binary polynomial division. Uses arithmetic addition.
Uses XOR operation. Uses one's complement arithmetic.
Strong error detection. Simple error detection.

Random Access vs Controlled Access

Random Access Controlled Access
Stations compete for the medium. Stations coordinate access.
Collisions may occur. Collisions can be reduced.
Examples: ALOHA, CSMA. Examples: Polling, Token Passing.
