1. Data Communication

What is Data Communication?

Data communication is the exchange of data between two or more devices through some form of transmission medium.

Simple Meaning:

One device has information → it sends the information → another device receives it.

Why is Data Communication Needed?

Modern computing rarely happens on a completely isolated computer. Computers need to exchange files, messages, commands, multimedia and other information.

Real-Life Example:

When you send a photo from your phone to a friend:

Your phone sends data → network carries the data → friend's phone receives the data.

Basic Data Communication Model

┌──────────┐ │ SENDER │ └────┬─────┘ │ │ Message ↓ ┌──────────────┐ │ Transmission │ │ Medium │ └──────┬───────┘ │ ↓ ┌──────────┐ │ RECEIVER │ └──────────┘

Communication rules are controlled by a protocol.

2. Components of Data Communication

A data communication system has five fundamental components.

DATA COMMUNICATION │ ┌────────────────┼────────────────┐ ↓ ↓ ↓ Sender Message Receiver │ ↓ Transmission Medium │ ↓ Protocol

1. Message

The message is the information being communicated.

It may be:

  • Text
  • Numbers
  • Images
  • Audio
  • Video
  • Computer files
Example:
A WhatsApp text message is a message.

2. Sender

The sender is the device that sends the data.

Examples: computer, mobile phone, server, sensor.

3. Receiver

The receiver is the device that receives the data.

Examples: laptop, smartphone, server, IoT device.

4. Transmission Medium

The transmission medium is the physical or wireless path through which data travels.

Examples include copper cable, optical fiber and radio waves.

5. Protocol

A protocol is a set of rules that controls communication between devices.

Easy Example:

Human conversation also follows rules.
One person speaks → another listens → response is given.

Computer networks similarly require communication rules.

3. Characteristics of Data Communication

A good data communication system should satisfy important characteristics.

1. Delivery

Data must reach the correct destination.

Example: If you send an email to your friend, it should reach your friend's email account and not another user's account.

2. Accuracy

Data should arrive without unacceptable errors or unwanted changes.

Example: If you send:

1000

the receiver should not incorrectly receive:

1001

3. Timeliness

Data should arrive at the appropriate time.

Timeliness is particularly important for live applications such as video calls and online gaming.

4. Jitter

Jitter refers to variation in the arrival time of packets.

Suppose packets of a voice call arrive at:

10 ms → 10 ms → 10 ms → 100 ms

The large variation can produce poor audio quality.

4. Data Flow

Data flow describes the direction in which data travels between devices.

1. Simplex

In simplex communication, communication occurs in only one direction.

Sender ─────────────────────► Receiver
Example:
Traditional television broadcasting.
TV station → viewer.

2. Half-Duplex

Both devices can communicate, but not at the same time.

Device A ─────────────► Device B Device A ◄───────────── Device B One direction at a time.
Example: Walkie-talkie communication. One person speaks while the other waits.

3. Full-Duplex

Both devices can communicate simultaneously.

Device A ◄════════════════► Device B Both directions simultaneously
Example: Telephone or modern voice communication.
Mode Direction Example
Simplex One direction Broadcast TV
Half-Duplex Both directions, one at a time Walkie-talkie
Full-Duplex Both directions simultaneously Telephone

5. Computer Networks

Definition

A computer network is a collection of interconnected computing devices that communicate and exchange data and resources.

Simple idea:

Devices + Communication Links + Protocols = Network

Why do we need Computer Networks?

  • Resource sharing
  • File sharing
  • Communication
  • Internet access
  • Hardware sharing
  • Centralized services
  • Remote access
College Example:

Computers in a college laboratory can be connected through a LAN so that they can access common servers, printers, storage and Internet services.

6. Network Criteria

A network can be evaluated using important criteria.

1. Performance

Performance describes how quickly and efficiently a network can deliver data.

Important measures include throughput and delay.

2. Reliability

Reliability indicates how consistently the network operates and how quickly it can recover from failures.

3. Security

Security protects data and network resources from unauthorized access, modification and attacks.

Example:
A banking network must provide strong security because financial information is sensitive.

7. Types of Networks

1. PAN — Personal Area Network

A PAN covers a very small area around an individual.

Example:
Smartphone connected to wireless earbuds or smartwatch.

2. LAN — Local Area Network

A LAN covers a limited geographical area such as a room, building, laboratory or office.

Example: College computer laboratory network.

3. MAN — Metropolitan Area Network

A MAN generally covers a city or metropolitan area and is larger than a LAN.

Example: A network connecting branches of an organization across a city.

4. WAN — Wide Area Network

A WAN covers large geographical areas such as countries or continents.

Example: The Internet is the most prominent example of a large interconnected network.
Network Coverage Example
PAN Very small personal area Phone + smartwatch
LAN Room/building/campus College lab
MAN City City-wide organization network
WAN Country/continent/world Internet

8. Network Topologies

Network topology describes the physical or logical arrangement of devices and communication links in a network.

1. Mesh Topology

In a mesh topology, devices are connected to multiple or all other devices.

A────────────B │╲ ╱│ │ ╲ ╱ │ │ ╲ ╱ │ │ ╲ ╱ │ │ ╲ ╱ │ │ ╲╱ │ C────────────D

Advantages

  • High reliability.
  • Multiple paths are available.
  • Failure of one link may not stop communication.
  • Good fault tolerance.

Disadvantages

  • Large amount of cabling.
  • Expensive.
  • Complex installation.

2. Star Topology

Every device is connected to a central device such as a switch.

PC │ │ PC ─── SWITCH ─── PC │ │ PC

Advantages

  • Easy to install.
  • Easy to troubleshoot.
  • Easy to add devices.
  • Failure of one cable usually affects one device.

Disadvantage

Failure of the central device can affect the entire network.

3. Bus Topology

All devices share a common backbone cable.

PC ───── PC ───── PC ───── PC ═══════════════════════════════ Backbone

Advantages

  • Simple design.
  • Requires less cable than mesh.
  • Can be inexpensive for small networks.

Disadvantages

  • Backbone failure can affect the network.
  • Performance can decrease as traffic increases.
  • Fault detection can be difficult.

4. Ring Topology

Each device is connected to two neighboring devices, forming a closed loop.

┌──────── PC ────────┐ │ │ PC PC │ │ └──────── PC ────────┘

Advantages

  • Organized access to the medium.
  • Can provide predictable transmission behavior.

Disadvantages

  • Failure can affect communication depending on design.
  • Adding/removing nodes can be more difficult.

Topology Comparison

Topology Main Feature Major Advantage Major Disadvantage
Mesh Many direct links High reliability Expensive
Star Central device Easy management Central-device dependency
Bus Common backbone Simple Backbone failure
Ring Closed loop Organized communication Failure can affect the ring

9. Protocols

What is a Protocol?

A protocol is a set of rules that governs communication between network devices.

Two devices need common rules so that the receiver can correctly understand the information sent by the sender.

Important Elements of a Protocol

  1. Syntax: Structure or format of data.
  2. Semantics: Meaning of each section of the data.
  3. Timing: When data should be sent and how quickly it should be processed.
Example:

HTTP defines rules used for communication between web clients and web servers.

10. Protocol Layering

Network communication is complex. Instead of handling everything as one huge task, networking functions are divided into layers.

Basic Idea:

Break a complex communication problem into smaller, manageable responsibilities.

Why Layering?

  • Reduces complexity.
  • Makes design easier.
  • Allows independent development of layers.
  • Makes troubleshooting easier.
  • Supports standardization.
  • Allows technologies to evolve independently.

Simple Layering Example

APPLICATION │ ↓ TRANSPORT │ ↓ NETWORK │ ↓ DATA LINK │ ↓ PHYSICAL

Each layer performs its own task and provides services to the layer above it.

11. TCP/IP Protocol Suite

TCP/IP is the protocol architecture used by the Internet and many modern computer networks.

TCP/IP Layers

┌──────────────────────────┐ │ APPLICATION │ ├──────────────────────────┤ │ TRANSPORT │ ├──────────────────────────┤ │ INTERNET │ ├──────────────────────────┤ │ NETWORK ACCESS / │ │ LINK + PHYSICAL │ └──────────────────────────┘

1. Application Layer

The application layer provides services used by network applications.

Examples include:

  • HTTP / HTTPS
  • FTP
  • DNS
  • SMTP
When you open a website, application-level protocols help your browser communicate with the web server.

2. Transport Layer

The transport layer provides communication between application processes.

Important protocols include:

  • TCP — Transmission Control Protocol
  • UDP — User Datagram Protocol

TCP provides reliable, connection-oriented transport, while UDP provides a simpler connectionless transport service.

3. Internet Layer

The Internet layer is responsible for logical addressing and delivery of packets across interconnected networks.

IP is the central protocol of this layer.

4. Network Access Layer

This layer handles communication over the local network technology and the physical transmission medium.

Examples include Ethernet and Wi-Fi technologies.

Exam Memory:

Application → User/network services
Transport → Process-to-process communication
Internet → Packet delivery between networks
Network Access → Local delivery and physical transmission

12. Logical Connection in TCP/IP

A logical connection means that corresponding entities at the same layer in communicating systems conceptually interact with each other.

The actual data does not physically travel directly between the same-layer entities. It moves downward through the sender's layers, across the network, and upward through the receiver's layers.

SENDER RECEIVER Application ◄══════════════════► Application │ │ Transport ◄══════════════════► Transport │ │ Internet ◄══════════════════► Internet │ │ Network ◄══════════════════► Network Access Access │ │ └────────── PHYSICAL ────────────┘ Actual data: Sender ↓↓↓ Layer by layer ↓↓↓ Network ↓↓↓ Receiver ↑↑↑ Layer by layer
VTU Point: When explaining logical connection, clearly distinguish between:

Logical interaction between peer layers
and
Actual physical transmission through lower layers and the communication network.

13. OSI Reference Model

OSI stands for Open Systems Interconnection. It is a seven-layer reference model used to describe network communication functions.

OSI MODEL 7 ┌─────────────────┐ │ Application │ 6 ├─────────────────┤ │ Presentation │ 5 ├─────────────────┤ │ Session │ 4 ├─────────────────┤ │ Transport │ 3 ├─────────────────┤ │ Network │ 2 ├─────────────────┤ │ Data Link │ 1 └─────────────────┘ │ Physical │ └─────────────────┘

7 Application Layer

Provides network services directly to applications.

Examples include web, email and file-transfer services.

Easy memory: "Services used by applications."

6 Presentation Layer

Handles representation-related functions such as translation, encryption and compression.

Easy memory: "How data is represented."

5 Session Layer

Establishes, manages and terminates communication sessions between applications.

Easy memory: "Manages conversations."

4 Transport Layer

Provides end-to-end or process-to-process communication.

It can provide functions such as segmentation, reassembly, flow control and reliability.

Easy memory: "Delivery between processes."

3 Network Layer

Responsible for logical addressing and routing packets between networks.

Easy memory: "Which path should the packet take?"

2 Data Link Layer

Provides node-to-node delivery over a data-link and handles framing and other link-level functions.

Easy memory: "Reliable link-level transfer."

1 Physical Layer

Transmits raw bits over the physical communication medium.

Easy memory: "Signals and bits."

14. Encapsulation and Decapsulation

Encapsulation

Encapsulation is the process in which each lower layer adds its own control information to data received from the layer above.

Application │ ↓ [ DATA ] │ ↓ Transport │ ↓ [ HEADER | DATA ] │ ↓ Network │ ↓ [ HEADER | HEADER | DATA ] │ ↓ Data Link │ ↓ [ HEADER | DATA | TRAILER ] │ ↓ Physical │ ↓ Bits

Decapsulation

At the receiving system, the process is reversed. Each layer removes and processes the information intended for it.

Sender → Encapsulation

Receiver → Decapsulation

15. OSI vs TCP/IP

OSI TCP/IP
Seven layers Commonly represented using four layers
Application, Presentation and Session are separate layers. These functions are largely included in the Application layer.
Data Link and Physical are separate. Common four-layer representation combines lower-layer functions as Network Access.
Developed as a general reference model. Developed around the Internet protocol suite.
Useful for conceptual understanding and standardization. Widely used in practical Internet networking.

Why did OSI not become the dominant practical protocol suite?

The OSI reference model remains important for understanding networking, but the TCP/IP protocol suite became dominant in the Internet.

Commonly discussed reasons include the earlier practical deployment and widespread adoption of TCP/IP, availability of working implementations, and the complexity and timing of OSI standardization.

Exam Tip: For the VTU question "Compare OSI and TCP/IP Models", first draw both models and then give a comparison table.

16. Introduction to Physical Layer

The physical layer is responsible for transmitting raw bits over a physical communication medium.

Major Concerns

  • Representation of bits
  • Data rate
  • Synchronization
  • Physical characteristics of interfaces
  • Transmission medium
Example:

When a computer sends binary data through a cable, the physical layer determines how those bits are represented as physical signals.

17. Transmission Media

Transmission media is the path through which data signals travel from one device to another.

TRANSMISSION MEDIA │ ┌───────────┴───────────┐ │ │ GUIDED UNGUIDED │ │ ┌─────┼─────┐ Wireless Signals │ │ │ Twisted Coaxial Fiber Pair Cable Optic

Two Major Categories

Guided media: Signal travels through a physical path.

Unguided media: Signal travels through air or free space.

18. Guided Transmission Media

In guided media, signals travel through a physical medium such as copper cable or optical fiber.

Main Types

  1. Twisted Pair Cable
  2. Coaxial Cable
  3. Fiber-Optic Cable
VTU Important: Guided transmission media and twisted pair cable are specifically asked in the official BCS502 model paper.

19. Twisted Pair Cable

Concept

A twisted pair cable consists of two insulated copper wires twisted around each other.

Wire 1 ~~~~~~~ ╲ ╱ X ╱ ╲ Wire 2 ~~~~~~~ Two insulated copper wires are twisted together.

Why are wires twisted?

Twisting helps reduce electromagnetic interference and crosstalk between nearby pairs.

Types

1. UTP — Unshielded Twisted Pair

UTP does not use an additional metallic shield around the twisted pairs.

2. STP — Shielded Twisted Pair

STP includes shielding that provides additional protection against electromagnetic interference.

UTP STP
No additional shielding Uses shielding
Lower cost Generally more expensive
Easy installation More complex installation
Common in Ethernet networks Useful where greater interference protection is needed

Advantages

  • Low cost.
  • Easy to install.
  • Flexible.
  • Widely available.

Disadvantages

  • More susceptible to interference than fiber.
  • Limited distance compared with fiber.
  • Signal quality can be affected by electromagnetic noise.
Example: Ethernet networks in homes, offices and computer labs commonly use twisted-pair cabling.

20. Coaxial Cable

Coaxial cable contains a central conductor surrounded by insulation, shielding and an outer protective layer.

┌─────────────────────┐ │ Outer Jacket │ │ ┌────────────────┐ │ │ │ Shield │ │ │ │ ┌────────────┐ │ │ │ │ │ Insulation │ │ │ │ │ │ ┌────────┐ │ │ │ │ │ │ │Conductor│ │ │ │ │ │ │ └────────┘ │ │ │ │ │ └────────────┘ │ │ │ └────────────────┘ │ └─────────────────────┘

Advantages

  • Better shielding than ordinary twisted pair.
  • Can carry signals over longer distances than some basic copper arrangements.

Applications

  • Cable television systems.
  • Some broadband communication systems.
  • Legacy network systems.

21. Optical Fiber

Optical fiber uses light to transmit information through a thin strand of glass or plastic.

┌───────────────────────────────────┐ │ JACKET │ │ ┌─────────────────────────┐ │ │ │ CLADDING │ │ │ │ ┌───────────────┐ │ │ │ │ │ CORE │ │ │ │ │ │ LIGHT ───► │ │ │ │ │ └───────────────┘ │ │ │ └─────────────────────────┘ │ └───────────────────────────────────┘

Basic Working

Information is converted into light signals. The light travels through the fiber core and is detected at the receiving end.

Main Parts

  • Core: carries the light.
  • Cladding: surrounds the core and helps keep light confined within it.
  • Jacket: provides physical protection.

Advantages

  • Very high bandwidth.
  • Low attenuation over long distances.
  • Immune to electromagnetic interference.
  • Lightweight compared with many copper systems.
  • Good security characteristics.

Disadvantages

  • Higher installation cost.
  • More delicate than ordinary copper cable.
  • Splicing and repair require specialized equipment.
Example: Fiber-optic links are widely used in high-speed telecommunications and Internet backbone networks.

22. Unguided / Wireless Media

In unguided transmission, electromagnetic signals travel through free space rather than through a physical cable.

Common Wireless Media

Medium Typical Idea Example
Radio Waves Can propagate over relatively broad areas and may support mobility. Wireless communication
Microwaves Directional communication, often used for point-to-point links. Microwave backhaul
Infrared Short-range communication using infrared radiation. Remote controls
Simple Example: Wi-Fi is a wireless networking technology in which radio waves are used to communicate between devices and access points.

23. Switching

What is Switching?

Switching is the process of selecting a path through a network so that data can travel from a source to a destination.

Source │ ↓ Router A / \ / \ Router B Router C \ / \ / Router D │ ↓ Destination

Main Switching Approaches

  • Circuit Switching
  • Packet Switching
  • Message Switching
For the current VTU BCS502 Module 1 syllabus, Packet Switching and its types are specifically included.

24. Packet Switching

Concept

In packet switching, a message is divided into smaller units called packets.

ORIGINAL MESSAGE ┌─────────────────────────────┐ │ LARGE MESSAGE │ └─────────────────────────────┘ │ ↓ Divided │ ┌──────────┼──────────┐ ↓ ↓ ↓ Packet 1 Packet 2 Packet 3 │ │ │ └──────────┼──────────┘ ↓ Network ↓ Destination ↓ Reassembled

Why Packet Switching?

  • Efficient sharing of network links.
  • Suitable for bursty data traffic.
  • Multiple users can share network resources.
  • Does not require a dedicated physical path for every communication session.

Types of Packet Switching

  1. Connectionless Packet Switching — Datagram Network
  2. Connection-Oriented Packet Switching — Virtual Circuit

25. Connectionless Packet Switching — Datagram Network

Concept

In a datagram network, each packet is treated independently.

Packets belonging to the same message may potentially take different routes.

┌──── Router B ─────┐ │ │ Sender ─ Router A Router D ─ Destination │ │ └──── Router C ─────┘ Packet 1 → B → D Packet 2 → C → D Packet 3 → B → D

Important Characteristics

  • No dedicated path is established before transmission.
  • Each packet contains destination information.
  • Packets are forwarded independently.
  • Different packets may take different paths.

Advantages

  • Flexible routing.
  • Efficient use of network resources.
  • No connection-establishment phase.

Disadvantages

  • Packets can experience different delays.
  • Packets may arrive out of order.
  • Packets may need reordering at the destination.

26. Connection-Oriented Packet Switching — Virtual Circuit

Concept

In a virtual-circuit network, a logical path is established before data packets are sent.

Connection Setup Sender │ ▼ Router A │ ▼ Router B │ ▼ Destination ↓ Virtual Circuit Established ↓ Packets follow the logical path

Three General Phases

  1. Setup: Establish the logical path.
  2. Data Transfer: Transfer packets using the established path.
  3. Teardown: Release the logical connection.

Datagram vs Virtual Circuit

Datagram Virtual Circuit
Connectionless Connection-oriented
No setup phase Setup phase exists
Each packet routed independently Packets normally follow established logical path
Packets may take different paths Packets generally follow the same logical route
Flexible Provides connection-oriented behavior

✍️ 28. 2-Mark Questions and Answers

1. Define data communication.
Data communication is the exchange of data between two or more devices through a communication medium.
2. List the components of data communication.
Message, sender, receiver, transmission medium and protocol.
3. What is a protocol?
A protocol is a set of rules that governs communication between network devices.
4. What is topology?
Topology is the physical or logical arrangement of devices and communication links in a network.
5. What is LAN?
LAN is a Local Area Network that covers a relatively limited geographical area such as a room, building, laboratory or campus.
6. What is TCP/IP?
TCP/IP is a suite of communication protocols used for communication across interconnected networks and forms the basis of Internet networking.
7. What is OSI?
OSI stands for Open Systems Interconnection. It is a seven-layer reference model for understanding network communication functions.
8. What is guided media?
Guided media is a transmission medium in which signals travel through a physical path such as copper cable or optical fiber.
9. What is packet switching?
Packet switching is a method in which data is divided into packets and packets are forwarded through a shared network.
10. What is a datagram network?
A datagram network is a connectionless packet-switched network in which each packet is treated independently.
11. What is jitter?
Jitter is the variation in packet arrival time.
12. What is full-duplex communication?
Full-duplex communication allows both devices to send and receive data simultaneously.
