1. Context-Free Languages

1.1 What is a Context-Free Language?

A language is called a Context-Free Language (CFL) if it can be generated by a Context-Free Grammar (CFG). 

CFG  →  generates  →  CFL
S → aSb | ε

generates: 

ε
ab
aabb
aaabbb
aaaabbbb
...

Therefore: 

L = { aⁿbⁿ | n ≥ 0 }

1.2 Why do we simplify CFG?

A grammar may contain unnecessary or complicated productions. Before converting a grammar into a normal form, we often simplify it.

The major simplification steps are:

  1. Remove ε-productions.
  2. Remove unit productions.
  3. Remove useless symbols.
Important: These three conversions are frequently asked as step-by-step problems.

2. Elimination of ε-Productions

2.1 What is an ε-production?

A production of the form: 

A → ε

is called an ε-production.

Here ε represents the empty string.

2.2 Basic procedure

  1. Find all nullable variables.
  2. For every production containing nullable variables, create alternatives by removing nullable variables.
  3. Remove the ε-productions.
  4. Keep S → ε only when the original language requires ε.

Problem 1 — Remove ε-Productions

Given: 

S → AB
A → aA | ε
B → bB | ε
Step 1 — Find nullable variables

A is nullable because: 

A → ε

B is nullable because: 

B → ε

Therefore: 

Nullable = {A, B}
Step 2 — Examine S → AB

Both A and B are nullable. Therefore we generate all useful combinations: 

AB
A
B
ε

So: 

S → AB | A | B | ε
Step 3 — Remove ε from A and B

Original: 

A → aA | ε
B → bB | ε

becomes: 

A → aA | a

B → bB | b
Step 4 — Decide about S → ε

Since the original grammar can generate ε, we retain: 

S → ε
Final grammar: 
S → AB | A | B | ε

A → aA | a

B → bB | b

Problem 2 — More Detailed ε-Elimination

Given: 

S → ABC
A → aA | ε
B → bB | ε
C → c
Step 1 — Identify nullable variables 
A → ε

B → ε

C is NOT nullable.

Therefore: 

Nullable = {A, B}
Step 2 — Expand S → ABC

Because A and B can disappear, we generate: 

ABC
BC
AC
C

We do not remove C because C is not nullable.

Step 3 — Remove ε from A and B 
A → aA | a

B → bB | b

C → c
Final grammar: 
S → ABC | BC | AC | C

A → aA | a

B → bB | b

C → c
Exam Tip: If two nullable variables occur together, remember that you must consider: 
Keep both
Remove first
Remove second
Remove both
Do not simply delete all nullable variables.

3. Elimination of Unit Productions

3.1 Definition

A production of the form: 

A → B

where both A and B are variables, is called a unit production.

Problem 3 — Remove Unit Productions

Given: 

S → A | b
A → B | a
B → C | b
C → c
Step 1 — Identify unit productions 
S → A
A → B
B → C
Step 2 — Find productions of A

A reaches B. B reaches C. C produces c.

Therefore A can ultimately produce: 

a
b
c
Step 3 — Find productions of B

B reaches C.

C produces c.

B also directly produces b.

Therefore: 

B → b | c
Step 4 — Find productions of S

S can reach A, then B, then C.

Therefore S can generate: 

a
b
c
Step 5 — Remove all unit productions 
S → a | b | c

A → a | b | c

B → b | c

C → c
Final Answer: 
S → a | b | c
A → a | b | c
B → b | c
C → c

There are no productions of the form A → B.

Problem 4 — Unit Chain

Given: 

S → A
A → B
B → C
C → aC | b
Step 1

C has no unit production. 

C → aC | b
Step 2

B → C means B gets all non-unit productions of C: 

B → aC | b
Step 3

A → B means A gets: 

A → aC | b
Step 4

S → A means: 

S → aC | b
Final grammar: 
S → aC | b

A → aC | b

B → aC | b

C → aC | b

4. Elimination of Useless Symbols

4.1 What is a useless symbol?

A symbol is useless if it cannot contribute to the generation of a terminal string from the start symbol.

There are two major reasons:

  1. The symbol is non-generating.
  2. The symbol is unreachable.

Problem 5 — Remove Useless Symbols

Given: 

S → AB | C
A → a
B → b
C → D
D → E
E → e
F → f
Step 1 — Find generating variables

A generates a: 

A → a

B generates b: 

B → b

E generates e: 

E → e

Therefore D generates e: 

D → E → e

C generates e: 

C → D → E → e

F generates f.

Therefore all variables appear generating.

Step 2 — Check reachability from S

Start: 

S

From S: 

S → A B
S → C

Therefore A, B and C are reachable.

From C: 

C → D

Therefore D is reachable.

From D: 

D → E

Therefore E is reachable.

Step 3 — Check F

There is: 

F → f

But there is no production from S, A, B, C, D or E that reaches F.

Therefore F is unreachable.

Step 4 — Remove F

Delete: 

F → f
Final grammar: 
S → AB | C

A → a

B → b

C → D

D → E

E → e

F has been removed because it is unreachable.

Problem 6 — Non-generating Symbol

Given: 

S → AB
A → a
B → C
C → D
D → C
Step 1 — Find directly generating variables 
A → a

So A is generating.

Step 2 — Check B 
B → C
C → D
D → C

There is no production from C or D that eventually produces a terminal.

Therefore: 

B, C, D = non-generating
Step 3 — Effect on S

S requires: 

S → AB

But B cannot generate a terminal string. Therefore S cannot generate any terminal string.

Conclusion:

The grammar generates no terminal string. The non-generating chain B, C, D is useless.

5. Chomsky Normal Form (CNF)

5.1 Definition

A CFG is in Chomsky Normal Form if its productions are generally of the form: 

A → BC

A → a

where A, B and C are variables and a is a terminal.

The start symbol may also have: 

S → ε

when ε belongs to the language.

5.2 Why CNF?

  • Useful for theoretical analysis.
  • Used in parsing algorithms such as CYK.
  • Provides a standard structure for CFGs.
  • Simplifies proofs involving context-free languages.

Problem 7 — Convert CFG to CNF

Given: 

S → aAB
A → a
B → b
Step 1 — Identify the problem

The production: 

S → aAB

contains three symbols on the right-hand side. CNF allows only two variables: 

A → BC

or one terminal: 

A → a
Step 2 — Replace terminal a

Introduce a new variable: 

X → a

Replace a by X: 

S → XAB
Step 3 — Break three variables

Introduce another variable: 

Y → AB

Then: 

S → XY
Step 4 — Check every production 
S → XY
X → a
Y → AB
A → a
B → b

Every production now has one of the allowed forms.

Final CNF: 
S → XY

Y → AB

X → a

A → a

B → b

Problem 8 — Complete CNF Conversion

Convert: 

S → aAB | bB
A → aA | ε
B → bB | b
into CNF.
Step 1 — Remove ε-production

A is nullable: 

A → ε

So from: 

S → aAB

we obtain: 

S → aAB | aB

For: 

A → aA

we add: 

A → a

Thus: 

S → aAB | aB | bB

A → aA | a

B → bB | b
Step 2 — Replace terminals in mixed productions

Introduce: 

X → a

Y → b

Then: 

S → XAB | XB | YB

A → XA | a

B → YB | b
Step 3 — Break XAB

Introduce: 

C → AB

Then: 

S → XC

The other productions remain: 

S → XB | YB

C → AB

A → XA | a

B → YB | b

X → a

Y → b
Step 4 — Check CNF

All productions are now either: 

Variable → Variable Variable

or

Variable → Terminal
Final CNF: 
S → XC | XB | YB

C → AB

A → XA | a

B → YB | b

X → a

Y → b

Problem 9 — CNF for S → aSb | ab

Step 1 — Original grammar 
S → aSb | ab
Step 2 — Replace terminals

Introduce: 

A → a

B → b

Then: 

S → ASB | AB
Step 3 — Break ASB

Introduce: 

C → SB

Then: 

S → AC | AB
Final CNF: 
S → AC | AB

C → SB

A → a

B → b
CNF Exam Shortcut: When you see something like: 
A → abc
think: 
X → a
Y → b
Z → c

A → XY
XY → Z
More systematically, introduce variables and break the RHS into pairs.

6. Greibach Normal Form (GNF)

6.1 Definition

A CFG is in Greibach Normal Form when productions generally have the form: 

A → aα

where:

  • a is a terminal.
  • α is a possibly empty string of variables.

Therefore the first symbol on the right side must always be a terminal.

Problem 10 — Convert a Simple Grammar to GNF

Given: 

S → AB

A → a

B → b
Step 1 — Check A 
A → a

This already starts with a terminal.

Step 2 — Substitute A into S 
S → AB

Since: 

A → a

we get: 

S → aB
Step 3 — Check B 
B → b

This is already GNF.

Final GNF: 
S → aB

A → a

B → b
Important: GNF conversion can become considerably more complicated for grammars containing recursion, nullable productions and indirect substitutions. For an exam, first simplify the grammar and remove ε-productions and unit productions before attempting a full GNF conversion.

7. Pumping Lemma for Context-Free Languages

7.1 Purpose

The CFL Pumping Lemma is mainly used to prove that certain languages are not context-free.

7.2 Statement

If L is a context-free language, then there exists a pumping length p such that every string z in L with: 

|z| ≥ p
can be written as: 

z = uvwxy
such that: 

1. |vwx| ≤ p

2. |vx| ≥ 1

3. uvⁱwxⁱy ∈ L for every i ≥ 0

7.3 Meaning

The middle portion: 

vwx
is limited in length. The pieces: 

v and x
are the parts that can be pumped.

Problem 11 — Prove L = { aⁿbⁿcⁿ | n ≥ 0 } is not context-free

Step 1 — Assume the opposite

Assume: 

L = {aⁿbⁿcⁿ | n ≥ 0}

is context-free.

Step 2 — Choose pumping length

Let p be the pumping length.

Step 3 — Choose a string

Choose: 

z = aᵖbᵖcᵖ

Clearly: 

|z| = 3p ≥ p
Step 4 — Apply pumping lemma

Write: 

z = uvwxy
with: 

|vwx| ≤ p
|vx| ≥ 1
Step 5 — Analyze possible locations

Because vwx has length at most p, it cannot cover all three blocks: 

aaaa...bbbb...cccc
inside a's

inside b's

inside c's

across a/b boundary

across b/c boundary

But it cannot include both a's and c's, because the b-block between them has length p.

Step 6 — Pump

Choose i = 0 or i = 2. Since v and x occur in at most two adjacent symbol blocks, pumping changes the number of symbols in one or two blocks but not all three equally.

Therefore after pumping: 

# of a's, # of b's, # of c's

cannot remain equal.

Step 7 — Contradiction

The pumped string is not of the form: 

aⁿbⁿcⁿ

Therefore: 

uvⁱwxⁱy ∉ L
for a suitable i.

Conclusion: 
L = {aⁿbⁿcⁿ | n ≥ 0}

is NOT a context-free language.

Problem 12 — Prove L = { aⁿbⁿcᵐ | n,m ≥ 0 } is context-free

Step 1 — Observe the language

The language requires equal numbers of a and b, while c can occur independently.

Step 2 — Construct a CFG 
S → AB

A → aAb | ε

B → cB | ε
Step 3 — Check A 
A → aAb | ε

generates: 

ε
ab
aabb
aaabbb
...

Therefore: 

L(A) = {aⁿbⁿ | n ≥ 0}
Step 4 — Check B 
B → cB | ε

generates: 

ε
c
cc
ccc
...
Conclusion:

Since we constructed a CFG for the language, the language is context-free.

Problem 13 — Pumping Lemma Proof Strategy

To prove a language is not context-free, follow this exact exam sequence:

Step 1
Assume L is context-free.
Step 2
Let p be the pumping length.
Step 3
Choose a suitable string z ∈ L
with |z| ≥ p.
Step 4
Write z = uvwxy.
Step 5
Use |vwx| ≤ p
and |vx| ≥ 1.
Step 6
Consider i = 0 or i = 2.
Step 7
Show uvⁱwxⁱy ∉ L.
Step 8
Contradiction.
Therefore L is not context-free.

8. Closure Properties of CFL

8.1 CFLs are closed under

  • Union
  • Concatenation
  • Kleene star
  • Reversal

8.2 CFLs are NOT closed under

  • Intersection
  • Complement
  • Difference

Problem 14 — Union of CFLs

Suppose: 

L1 = {aⁿbⁿ | n ≥ 0}

L2 = {cⁿdⁿ | n ≥ 0}

Both are CFLs.

Step 1 — Create grammars 
S1 → aS1b | ε

S2 → cS2d | ε
Step 2 — Combine them 
S → S1 | S2
Conclusion:

The union is context-free.

Problem 15 — Concatenation of CFLs

Let: 

L1 = {aⁿ | n ≥ 0}

L2 = {bᵐ | m ≥ 0}

Both are regular and therefore CFL.

Step 1
S1 → aS1 | ε
Step 2
S2 → bS2 | ε
Step 3 — Concatenate
S → S1S2
Therefore: 
L1L2
is context-free.
Remember for exam:
Operation CFL?
Union Closed
Concatenation Closed
Kleene Star Closed
Reversal Closed
Intersection Not closed
Complement Not closed
Difference Not closed

9. CNF vs GNF

Feature CNF GNF
Full form Chomsky Normal Form Greibach Normal Form
Typical production A → BC or A → a A → aα
First RHS symbol May be variable Must be terminal
Use Parsing and theoretical analysis Derivation / PDA-related theoretical results

10. How to Write Conversion Problems in VTU Exam

For ε-Production Removal

  1. Find nullable variables.
  2. Generate alternatives.
  3. Remove ε-productions.
  4. Keep S → ε if necessary.
  5. Write final grammar.

For Unit Production Removal

  1. Identify A → B productions.
  2. Find all reachable variables through unit chains.
  3. Copy non-unit productions.
  4. Delete unit productions.

For Useless Symbol Removal

  1. Find generating variables.
  2. Remove non-generating symbols.
  3. Check reachable symbols.
  4. Remove unreachable symbols.

For CNF

  1. Remove ε-productions.
  2. Remove unit productions.
  3. Remove useless symbols.
  4. Replace terminals in long RHS expressions.
  5. Break RHS expressions longer than two symbols.
  6. Write final CNF.

For Pumping Lemma

  1. Assume the language is CFL.
  2. Let p be the pumping length.
  3. Choose a suitable string.
  4. Apply z = uvwxy.
  5. Use |vwx| ≤ p.
  6. Use |vx| ≥ 1.
  7. Choose a pumping value such as i = 0 or 2.
  8. Show the resulting string is not in L.
  9. State contradiction.
