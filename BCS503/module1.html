📚 Module 1: Finite Automata

This module introduces the basic concepts of Automata Theory, Finite Automata, DFA, NFA, ε-NFA, structural representations, and applications such as text searching.

🎯 Exam Focus: DFA construction, NFA construction, NFA to DFA conversion, ε-closure and finite automata concepts are especially important.

1. Introduction to Automata Theory

Automata Theory is a branch of computer science that studies mathematical models of computation called automata.

An automaton is an abstract machine that receives input, processes the input, changes its state and finally accepts or rejects the input.

Simple Example

Consider a machine that accepts only binary strings ending in 01. 

Input: 1101

1 → 1 → 0 → 1

Ends with 01
Therefore: ACCEPT

If the input is 1100, it does not end with 01, so it is rejected.

2. Finite Automaton

A Finite Automaton (FA) is a mathematical model of computation having a finite number of states.

It reads an input string symbol by symbol and determines whether the string belongs to a particular language.

Input String ↓ ┌─────────────────┐ │ Finite │ │ Automaton │ └─────────────────┘ ↓ Accept / Reject

Applications

  • Compiler design
  • Lexical analysis
  • Pattern matching
  • Text searching
  • Regular expressions
  • Communication protocols
  • Digital circuit design

3. Central Concepts of Automata Theory

Four basic concepts are:

  1. Alphabet
  2. String
  3. Language
  4. Automaton
Alphabet ↓ Strings ↓ Language ↓ Automaton ↓ Accept / Reject

4. Alphabet

An alphabet is a finite, non-empty set of symbols. It is generally represented by the Greek letter Σ.

Examples

Σ = {0, 1}

Σ = {a, b}

Σ = {a, b, c}
Remember: An alphabet contains symbols, not complete strings.

For example:

a  → symbol
b  → symbol
ab → string

5. String

A string is a finite sequence of symbols selected from an alphabet.

Example

Σ = {0,1}

101 → string

Σ = {a,b}

abba → string

Length of a String

The number of symbols present in a string is called its length. 

w = 10110

|w| = 5
        
w = abba

|w| = 4

6. Empty String

A string containing no symbols is called the empty string.

It is represented by: 

ε

The length of the empty string is:

|ε| = 0
Important: ε is not the same as the symbol 0.

7. Power of an Alphabet

Σⁿ represents the set of all strings of length n that can be formed using symbols from Σ.

Suppose:

Σ = {a,b}

Σ⁰

Σ⁰ = {ε}

Σ¹

Σ¹ = {a,b}

Σ²

Σ² = {aa, ab, ba, bb}

Σ³

Σ³ = {
aaa, aab, aba, abb,
baa, bab, bba, bbb
}

8. Σ* and Σ+

Σ*

Σ* represents the set of all possible finite strings over Σ, including the empty string. 

Σ* = Σ⁰ ∪ Σ¹ ∪ Σ² ∪ Σ³ ∪ ...

Σ+

Σ+ represents all non-empty strings. 

Σ+ = Σ¹ ∪ Σ² ∪ Σ³ ∪ ...
Concept Meaning Contains ε?
Σ* All finite strings Yes
Σ+ All non-empty strings No

9. String Concatenation

Joining two strings together is called concatenation. 

x = abc
y = 101

xy = abc101

Example

x = ab
y = ba

xy = abba
yx = baab
String concatenation is generally NOT commutative. Therefore, xy ≠ yx.

10. Language

A language is a set of strings over an alphabet.

Example

Σ = {0,1}

L = {0, 01, 101, 111}

The language may be finite or infinite.

Finite Language

L = {a, ab, aba}

Infinite Language

L = {a, aa, aaa, aaaa, ...}

12. DFA — Deterministic Finite Automaton

DFA stands for Deterministic Finite Automaton.

In a DFA, for every state and every input symbol, there is exactly one next state.

Formal Definition

M = (Q, Σ, δ, q₀, F)
Symbol Meaning
Q Finite set of states
Σ Input alphabet
δ Transition function
q₀ Initial state
F Set of final states

Transition Function

δ : Q × Σ → Q

This means that every state-input pair produces exactly one next state.

13. Example DFA

Construct a DFA that accepts binary strings ending in 1.

States

q0 = string does not currently end in 1
q1 = string ends in 1

Transition Table

State 0 1
→ q0 q0 q1
* q1 q0 q1

q0 is the initial state and q1 is the final state.

14. NFA — Nondeterministic Finite Automaton

NFA stands for Nondeterministic Finite Automaton.

In an NFA, for a state and input symbol, there can be zero, one or multiple possible next states.

Formal Representation

M = (Q, Σ, δ, q₀, F)

Transition Function

δ : Q × Σ → 2^Q

The result can be a set of states.

Example

┌────→ q1 │ q0 ─── a ───┤ │ └────→ q2

From q0 on input a, the machine can go to q1 or q2. Therefore, it is an NFA.

15. DFA vs NFA

DFA NFA
Deterministic Nondeterministic
Exactly one transition Zero, one or multiple transitions
No ε-transition ε-transition is possible in ε-NFA
δ : Q × Σ → Q δ : Q × Σ → 2^Q
One possible path Multiple possible paths
Recognizes regular languages Recognizes regular languages
⭐ Important: DFA and NFA have the same computational power. Both recognize regular languages.

16. NFA Acceptance

An NFA accepts a string if at least one possible computation path ends in a final state after consuming the complete input.

a ┌──────→ q1* │ q0 ──────────┤ │ └──────→ q2

If one possible path reaches a final state, the input is accepted.

17. ε-NFA

An ε-NFA is a finite automaton that allows transitions without consuming an input symbol.

The symbol used for such a transition is: 

ε
q0 ─── ε ───→ q1

The machine can move from q0 to q1 without reading an input symbol.

18. ε-Closure

The ε-closure of a state q is the set of all states reachable from q using zero or more ε-transitions.

Example

q0 ──ε──→ q1 ──ε──→ q2 
ε-closure(q0) = {q0, q1, q2}

ε-closure(q1) = {q1, q2}

ε-closure(q2) = {q2}
Remember: The starting state is always included in its own ε-closure because zero ε-moves are allowed.

19. Text Search using Finite Automata

Finite automata can be used for pattern matching and text searching.

Suppose we want to search for: 

CAT

inside:

THE CAT IS ON THE MAT

We can construct an automaton representing the pattern:

q0 ──C──→ q1 ──A──→ q2 ──T──→ q3*

When the automaton reaches q3, the pattern has been found.

20. Automata and Complexity

Automata provide mathematical models for studying computation. Different types of automata have different computational capabilities.

Finite Automata ↓ Pushdown Automata ↓ Turing Machines

Finite Automata are mainly used for recognizing regular languages.

21. DFA Construction — General Method

  1. Understand the given language.
  2. Determine what information must be remembered.
  3. Create suitable states.
  4. Identify the initial state.
  5. Identify the final state or states.
  6. Fill all transitions.
  7. Test the DFA using accepted and rejected strings.
Exam Tip: In a DFA, every state must have exactly one transition for every symbol in the input alphabet.

22. Example — DFA for Even Number of 0s

Language: All strings over {0,1} containing an even number of zeros.

States

q0 = even number of 0s
q1 = odd number of 0s

Initial state = q0

Final state = q0

Transition Table

State 0 1
→ *q0 q1 q0
q1 q0 q1

Reading 0 changes even to odd or odd to even. Reading 1 does not change the number of zeros.

23. Important Definitions

Alphabet

A finite non-empty set of symbols is called an alphabet.

String

A finite sequence of symbols from an alphabet is called a string.

Empty String

A string containing no symbols is called an empty string and is represented by ε.

Language

A set of strings over an alphabet is called a language.

Finite Automaton

A finite automaton is an abstract machine with a finite number of states used to recognize languages.

DFA

A deterministic finite automaton has exactly one transition for every state and input symbol.

NFA

A nondeterministic finite automaton may have zero, one or multiple transitions for a state and input symbol.

ε-NFA

An NFA that permits transitions without consuming an input symbol is called an ε-NFA.

ε-Closure

The set of states reachable from a state using zero or more ε-transitions is called its ε-closure.
