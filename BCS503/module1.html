1. Introduction to Finite Automata

Automata Theory is an important area of Computer Science that studies abstract mathematical machines and the problems that these machines can solve.

A finite automaton is a mathematical model of computation having a finite number of states. It reads an input string one symbol at a time and changes its state according to a transition rule.

Simple idea: A finite automaton can be imagined as a machine that reads a string, moves between states, and finally decides whether the string is accepted or rejected.

Example

Consider a machine that accepts binary strings ending in 1.

0 ┌─────────┐ ↓ │ → q0 ──1──→ q1* ↑ │ └──0─────┘ 1 ↺

Here:

  • q0 is the initial state.
  • q1 is the final state.
  • Input 1 moves the machine to q1.
  • Input 0 moves the machine to q0.

2. Basic Concepts

2.1 Alphabet

An alphabet is a finite, non-empty set of symbols. It is generally represented by the Greek letter Σ.

Examples:

Σ = {0,1}
Σ = {a,b}
Σ = {a,b,c}

2.2 String

A string is a finite sequence of symbols selected from an alphabet.

For:

Σ = {a,b}

some strings are:

a, b, aa, ab, ba, bb, aaa, aab, aba, ...

2.3 Empty String

The string containing no symbols is called the empty string. It is represented by:

ε

Its length is:

|ε| = 0

2.4 Length of a String

The number of symbols present in a string is its length.

w = ababa
|w| = 5

2.5 Language

A language is a set of strings over an alphabet.

For example:

L = {a, aa, aaa, aaaa, ...}

This language contains strings consisting only of one or more a symbols.

2.6 Power of an Alphabet

The notation Σⁿ represents the set of all strings of length n over alphabet Σ.

For:

Σ = {0,1}

we have:

Σ⁰ = {ε} Σ¹ = {0,1} Σ² = {00,01,10,11}

2.7 Kleene Star

The Kleene star is represented by:

Σ*

It represents all possible finite strings over Σ, including ε.

For:

Σ = {a,b}

we have:

Σ* = {ε, a, b, aa, ab, ba, bb, aaa, ...}

3. Structural Representation of Automata

Finite automata can be represented in different ways. The important representations are:

  1. Transition diagram
  2. Transition table
  3. Formal mathematical notation

3.1 Transition Diagram

A transition diagram represents states using circles and transitions using directed arrows.

0 ┌────────┐ ↓ │ → (q0) ─1→ ((q1)) ↑ │ └──1──

Conventions:

  • An arrow entering a state indicates the initial state.
  • A double circle represents a final state.
  • An arrow labelled with an input symbol represents a transition.

3.2 Transition Table

State 0 1
→ q0 q0 q1
* q1 q0 q1

3.3 Formal Representation

A finite automaton can be represented as:

M = (Q, Σ, δ, q₀, F)

where:

Symbol Meaning
Q Finite set of states
Σ Input alphabet
δ Transition function
q₀ Initial state
F Set of final states

4. Automata and Complexity

Automata provide simplified mathematical models of computational systems. Different automata have different computational capabilities.

Finite automata have limited memory because they have only a finite number of states.

A finite automaton cannot remember an unlimited amount of information. Therefore, it is suitable for recognizing regular languages.

Examples of applications include:

  • Lexical analysis in compilers
  • Text searching
  • Pattern matching
  • Input validation
  • Digital circuit design
  • Communication protocols

5. Central Concepts of Automata Theory

State

A state represents the current condition of the automaton.

Initial State

The state from which processing starts.

Final State

A state that indicates successful acceptance of the input.

Transition

A transition specifies how the automaton moves from one state to another when an input symbol is received.

Acceptance

After the complete input is consumed, if the automaton is in a final state, the input string is accepted. Otherwise it is rejected.

Accepted String → Final State Rejected String → Non-final State

6. Deterministic Finite Automata (DFA)

A Deterministic Finite Automaton is a finite automaton in which for every state and every input symbol there is exactly one next state.

Formal Definition

DFA = (Q, Σ, δ, q₀, F)

The transition function of a DFA is:

δ : Q × Σ → Q

Important properties of DFA

  • Exactly one transition for every state-input combination.
  • No ε-transitions.
  • There is exactly one initial state.
  • There can be one or more final states.
  • The machine processes one input symbol at a time.

Example: DFA accepting strings ending in 1

Alphabet:

Σ = {0,1}

States:

Q = {q0,q1}

Initial state:

q0

Final state:

F = {q1}
State 0 1
→ q0 q0 q1
* q1 q0 q1

Testing the string 101

q0 --1--> q1 --0--> q0 --1--> q1

The final state is q1. Therefore:

101 is accepted.

7. Solved DFA Problem

Problem

Construct a DFA over {0,1} that accepts strings containing at least one 1.

Step 1 — Identify states

We need two situations:

  • No 1 has appeared yet.
  • At least one 1 has appeared.
Therefore:

q0 = no 1 seen q1 = at least one 1 seen

Step 2 — Initial state

q0

Step 3 — Final state

Once a 1 has appeared, the string should be accepted. Therefore:

F = {q1}

Step 4 — Transition table

State 0 1
→ q0 q0 q1
* q1 q1 q1

Final DFA

1 ┌───────────┐ ↓ │ → q0 ───1──→ q1* ──┘ ↑ │ └─────0──────┘

Test

String:

000101

Processing:

q0 → q0 → q0 → q1 → q1 → q1

Final state = q1.

Therefore 000101 is accepted.

8. Non-Deterministic Finite Automata (NFA)

A Non-Deterministic Finite Automaton is a finite automaton in which a state may have zero, one, or multiple transitions for the same input symbol.

Formal definition

NFA = (Q, Σ, δ, q₀, F)

For an NFA:

δ : Q × Σ → 2^Q

This means that the transition can produce a set of states.

DFA vs NFA

Feature DFA NFA
Next state Exactly one Zero, one or many
ε-transition Not allowed Basic NFA does not use ε; ε-NFA does
Transition function Q × Σ → Q Q × Σ → 2^Q
Implementation Direct May require conversion
Power Both recognize exactly the regular languages

9. NFA Example

Problem

Construct an NFA over {0,1} that accepts strings ending with 01.

Idea

The NFA can remain in the starting state while searching for the beginning of the final 01.

0,1 ↺ q0 ──0──→ q1 ──1──→ q2*

Transition table

State 0 1
→ q0 {q0,q1} {q0}
q1 ∅ {q2}
* q2 ∅ ∅

The NFA accepts when there is a path that ends in q2 after consuming the complete input.

10. Finite Automata with ε-Transitions

An ε-transition allows an automaton to move from one state to another without consuming an input symbol.

ε = Empty String

Therefore, an ε-transition does not read a character from the input.

Example

ε ┌──────────→ q1 │ → q0 ───┤ │ └──────────→ q2 ε

From q0, the machine may move to q1 or q2 without reading an input symbol.

ε-Closure

The ε-closure of a state is the set of states reachable from that state using zero or more ε-transitions.

It always contains the state itself.

q ∈ ε-closure(q)

Example

q0 ──ε──→ q1 ──ε──→ q2

Therefore:

ε-closure(q0) = {q0,q1,q2} ε-closure(q1) = {q1,q2} ε-closure(q2) = {q2}

11. NFA to DFA Conversion

Every NFA can be converted into an equivalent DFA. The commonly used method is the subset construction method.

Basic steps

  1. Start with the initial state of the NFA.
  2. For each input symbol, find all possible destination states.
  3. Treat the resulting set of states as one DFA state.
  4. Continue until no new state sets are obtained.
  5. Any DFA state containing an NFA final state becomes a final state.

Simple example

Suppose:

NFA states = {q0,q1} Initial state = q0 Final state = q1

Suppose:

δ(q0,0) = {q0} δ(q0,1) = {q0,q1}

Then DFA states can include:

{q0} {q0,q1}

Since {q0,q1} contains the NFA final state q1, it becomes a DFA final state.

12. ε-NFA to DFA Conversion

For ε-NFA conversion, ε-closure is calculated at every required step.

Procedure

  1. Find ε-closure of the initial state.
  2. For every input symbol, find the set of reachable states.
  3. Take ε-closure of the resulting set.
  4. Use this new set as a DFA state.
  5. Repeat until all DFA states are processed.
  6. Mark states containing NFA final states as DFA final states.
Exam memory: For ε-NFA → DFA, remember:

ε-closure → Move → ε-closure → New DFA State

13. Application: Text Search

Finite automata can be used for pattern matching and text searching.

Suppose we want to search for the pattern:

"abc"

A finite automaton can have states representing how much of the pattern has already been matched.

q0 --a--> q1 --b--> q2 --c--> q3*

When the automaton reaches q3 after reading the required pattern, the pattern has been found.

Finite automata are therefore useful in pattern matching and text-search applications.

14. Important Solved Problems

Problem 1: Construct a DFA over {0,1} accepting strings beginning with 1.
States: q0 = Start q1 = String began with 1 qd = Dead state
State 0 1
→ q0 qd q1
* q1 q1 q1
qd qd qd
Problem 2: Construct a DFA accepting strings containing at least two 0s.
q0 = no 0 q1 = exactly one 0 q2 = at least two 0s

Final state:

F = {q2}
Problem 3: Construct a DFA accepting strings with an even number of 0s.
q0 = even number of 0s q1 = odd number of 0s

Start and final state:

q0
State 0 1
→ *q0 q1 q0
q1 q0 q1
Problem 4: Construct a DFA accepting binary strings divisible by 3.

Use states based on the remainder obtained when the binary value is divided by 3:

q0 = remainder 0 q1 = remainder 1 q2 = remainder 2

The initial and final state is q0.

This type of DFA construction appears in VTU model-paper problems.
Problem 5: Define NFA and convert a given NFA into an equivalent DFA.

For this type of question, use the subset construction method:

Start State ↓ Find transitions ↓ Create state sets ↓ Repeat ↓ Identify final states
